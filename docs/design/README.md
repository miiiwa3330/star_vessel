# デザイン

まだ何も決まっていない。世界観の方針（写実に寄せすぎない・軽さ優先）は [`../concept/README.md`](../concept/README.md)。

## 決まったこと

- 2026-11-05：**宇宙の中の天体に、大きな名前の表示を付けない。** 天体の名前は、レーダーの中に小さく出すだけにする。宇宙の景色を文字でふさがないため

- 2026-11-05：**天体の情報は、画面の隅のカードに出す**（要件 F36・F37）。宇宙の中には文字を出さない（上の決まりのまま）。PC は画面の上の真ん中、スマホは左上の状態の下（右上のレーダーに重ならないように）。選んだ天体には、宇宙の中に**文字の無い輪の印**を付け、画面の外なら、ふちにその向きを指す矢印を出す

- 2026-11-05：**画面の真ん中に小さな照準の輪を置き、照準の先の天体の名前と距離を、その下に 1 行だけ出す**（要件 F36）。画面に固定した表示で、宇宙の中の天体に付けた文字ではない。くわしい情報は、選んだときのカードに出す

- 2026-11-05：**操作の説明とクレジットは、左下の小さなボタン（「？ 操作」「クレジット」）にしまう**。押すと開く。操作の説明は、初めて遊ぶときだけ開いておく（端末に覚える）。クレジットは CC BY・CC BY-SA の表記のため、いつでも開けるようにする。スマホでは、速さのボタンを右下に置く（右上にレーダーとボタンがあり、右下が空くため）

- 2026-11-05：**レーダーの名前は重ねない**。ワープホール → 近い天体の順に、ほかの名前とほかの点の印にかからないものだけ、最大 5 つ出す（`chooseRadarLabels`）。名前は点の印より上に描き、まわりを暗くふちどる

- 2026-11-05：**左上の列は、状態の下に「スタンプ」「近く」「コレクション」の切り替えを置き、同時に開くのは 1 つだけ**（重ならないように）。届いたスタンプの履歴は、閉じていても出す

- 2026-11-05：**レーダーは画面の隅に置く**（PC は右下、スマホは右上）。自分の向きが基準の円。見え方の決まりは [`../tech/world-model.md`](../tech/world-model.md) の「レーダー」
