# デザイン

まだ何も決まっていない。世界観の方針（写実に寄せすぎない・軽さ優先）は [`../concept/README.md`](../concept/README.md)。

## 決まったこと

- 2026-11-05：**宇宙の中の天体に、大きな名前の表示を付けない。** 天体の名前は、レーダーの中に小さく出すだけにする。宇宙の景色を文字でふさがないため

- 2026-11-05：**天体の情報は、画面の隅のカードに出す**（要件 F36・F37）。宇宙の中には文字を出さない（上の決まりのまま）。PC は画面の上の真ん中、スマホは左上の状態の下（右上のレーダーに重ならないように）。選んだ天体には、宇宙の中に**文字の無い輪の印**を付け、画面の外なら、ふちにその向きを指す矢印を出す

- 2026-11-05：**画面の真ん中に小さな照準の輪を置き、照準の先の天体の名前と距離を、その下に 1 行だけ出す**（要件 F36）。画面に固定した表示で、宇宙の中の天体に付けた文字ではない。くわしい情報は、選んだときのカードに出す

- 2026-11-05：**星座の線は、青い細い線**（要件 F40）。照準の先の星座だけ明るくする。星座の名前は宇宙の中に出さず、照準の下に出す（上の決まりのまま）。最初は消しておき、右のボタンか C キーで出す
- 2026-11-05：**操作の説明とクレジットは、左下の小さなボタン（「？ 操作」「クレジット」）にしまう**。押すと開く。操作の説明は、初めて遊ぶときだけ開いておく（端末に覚える）。クレジットは CC BY・CC BY-SA の表記のため、いつでも開けるようにする。スマホでは、速さのボタンを右下に置く（右上にレーダーとボタンがあり、右下が空くため）

- 2026-11-05：**レーダーの名前は重ねない**。ワープホール → 近い天体の順に、ほかの名前とほかの点の印にかからないものだけ、最大 5 つ出す（`chooseRadarLabels`）。名前は点の印より上に描き、まわりを暗くふちどる

- 2026-11-05：**左上の列は、状態の下に「スタンプ」「近く」「コレクション」の切り替えを置き、同時に開くのは 1 つだけ**（重ならないように）。届いたスタンプの履歴は、閉じていても出す

- 2026-11-05：**レーダーは画面の隅に置く**（PC は右下、スマホは右上）。自分の向きが基準の円。見え方の決まりは [`../tech/world-model.md`](../tech/world-model.md) の「レーダー」

- 2026-11-06：**タイトル画面と準備画面は分ける**（オーナーの指示。要件 F48・[`../product/top-screen.md`](../product/top-screen.md)）。タイトル画面は景色が主役で、文字は最小限（名前・一言・「はじめる」・いま遊んでいる人数の 1 行だけ）。準備画面は、操縦席の画面と同じ部品（暗い半透明の面・水色の線・system-ui）で、宇宙船・アカウント・出発の順に縦に並べた 1 枚のカード
- 2026-11-06：**タイトル画面・準備画面の背景は、2D の星空と CSS の地球の縁**（→ 同じ日に、下の「3D の地球と本物の船」に置き換えた。CSS の縁は、3D が出るまでと、3D が使えないときの代わりとして残っている）。世界の描画（three.js）は使わない（軽く開くため）。昼の側の水色の縁と、地平線の向こうの太陽の薄い光。星は種を決めて並べるので、誰の端末でも同じ夜空。「動きを減らす」の設定では止める。色は `src/top/top.css` の `--top-*`（`src/ui/hud.css` と同じ値）
- 2026-11-06：**スマホでは、触れずに指せる端末だけにホバーの色を付ける**（`@media (hover: hover)`）。タップした場所に色が残らないように。入力欄の文字は 16px 以上（iPhone の Safari が拡大しないように）
- 2026-11-06：**回復コードは、保存したと確かめるまで閉じない**（要件 F51）。閉じると二度と見られないので、「保存しました」のチェックまで「閉じる」を押せず、Esc でも閉じない。後ろの画面は触れない（ブラウザの `<dialog>`）。コードは等幅の文字で 5 文字ずつ区切る

- 2026-11-06：**タイトル画面は、名前・一言・「-START-」だけにし、枠のあるボタンと人数の表示はやめる**（オーナーの指示）。「-START-」は枠の無い文字で、ゆっくり明るさが変わる。人数は準備画面に移した（**進むのは、はじめは画面のどこをタップしても、だったが、同じ日に、「-START-」のまわりをタップしたときだけに変えた**。下の決め）
- 2026-11-06：**名前の書体は Monoton（OFL）、色はオレンジ**（オーナーの指定）。細い線を重ねたネオンの管のような書体で、`#ff8a1f` に、オレンジの光のにじみ（`filter: drop-shadow`。`text-shadow` では線のかたちに沿わない）を付ける。幅が広いので、大きさは画面の幅の 11%（最大 112px）。「-START-」は、細い Josefin Sans（OFL）の 300。**（同じ日の前の決め：虹色に光るガラス調の塗りの Josefin Sans は、この指定で置き換えた。オーナーが添付した画像は文字の入っていない星のマークで、質感を再現するために、7 つの書体を虹色の塗りで見比べて選んだものだった）**
- 2026-11-06：**3D の地球と本物の船**（要件 F48・F53）。背景に、いまの時刻の本物の地球（世界の画面と同じ画像・自転・太陽の向き）を 3D で描く。地球の縁が画面の下に弧を描き、その上に、本物のプレイヤーの船が光の点と短い尾で浮かぶ。船がいなければ地球だけ（作り物の船は出さない）。大気の光は、世界の画面の約 45%（地球が大きく映るので、同じ強さだと太い帯に見える）。出典の 1 行（CC BY 4.0）を、画面の下の端に小さく出す
- 2026-11-06：**重ければ、事前に描いた画像 1 枚にする**（オーナーの決め）。いまは約 2 MB（画像 1.6 MB）。重いと感じたら切り替える。`?earth=css` で、いまでも CSS の縁だけにできる

- 2026-11-06：**タップして進むのは、「-START-」のまわりだけ**（オーナーの指示。それまでは画面全体）。見た目の文字の外側に、約 14〜20px 広げた範囲（約 330×110px）を押せるようにする。画面全体をタップにすると、スクロールして詳細を読めなくなり、アイコンも押しにくいため
- 2026-11-06：**読み込み中に、仮の球体は出さない**（オーナーの指示）。地球は、描ける状態（画像・描画の準備・シェーダーのコンパイルが終わった状態）になってから、**画面の下から約 1.6 秒かけて上がってきて、同時にゆっくり現れる**。CSS の球体は、3D を使わないときと、描けなかったときだけ
- 2026-11-06：**スクロールすると、背景の地球が動き、「最初の画面」と「詳細」の間で止まらない**。最初の画面では地球の上の縁が画面の下に、詳細の先頭では**地球の下半分が画面の上**に見える（カメラが約 1.8 倍に離れ、見る向きを上へ振る。地球の下の縁が、画面の上から約 4 割）。詳細の文字は、その下から始める。詳細より先へ進むと、地球はページと一緒に上へ出ていく
- 2026-11-06：**右上に、X と Miiiwa のアイコン**。42px の丸で、うっすら暗い丸を敷く（明るい地球の上でも見えるように）。Miiiwa のアイコンは、オーナーのロゴの形（オレンジの点と縦棒）で、棒を明るい色にした（暗い背景のため）
- 2026-11-06：**一言は細字**（font-weight 200）。日本語の細い書体は端末にあるものを使う。詳細の本文は 300、見出しは 300〜400
- 2026-11-06：**サービスの詳細の見せ方**：小さな英字の見出し（ABOUT・REAL DATA・PLAY・ACCOUNT。オレンジ・Josefin Sans）の下に、日本語の見出しと、短い文章。体験の核は 2×2 の面（スマホは 1 列）、数は、左に大きな数・右に説明の行
