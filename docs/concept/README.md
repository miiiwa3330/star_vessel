# コンセプト

## 一言で

**地球から飛び立ち、世界中のプレイヤーと同じ宇宙を、自分の宇宙船の一人称視点で旅するサービス。**

## 体験の核

1. **一人称で宇宙を進む**：操縦席から見た宇宙を、自分で動かして進む
2. **本物の宇宙がいま動いている**：惑星の位置・公転・自転は、現実のいまの時刻と同じ。地球の昼と夜も現実と一致する
3. **ひとりじゃない**：いま同時に遊んでいる世界中のプレイヤーが、宇宙船として同じ宇宙に見える
4. **みんな地球から始まる**：出発点は全員同じ地球。そこから銀河の規模まで遠くへ行ける

## 世界観の方針：位置と動きは本物、見た目は軽く

- **天体の位置と動きは、実世界に忠実にする。** 軌道・公転・自転は、現実の時刻に合わせて動かす
- **見た目は写実に寄せすぎない。** 写真のような描写よりも、軽く動いて気持ちよく探索できることを優先する
- **すべてを作り込まない。** 銀河の規模まで行けるが、すべての惑星を細かく再現はしない。実在のデータがある範囲はそれを使い、データの無い範囲は本物の銀河の形に沿って自動で生成する（データがどこまであるかは [`../tech/feasibility.md`](../tech/feasibility.md) の「実在のデータで再現できる範囲」）

## 進め方

**まずは世界の創造から。** 宇宙・天体・移動を先に作る。探索以外の遊びの要素は、そのあとで考える。

- 2026-11-04：探索できる規模は銀河まで。ただし全惑星の細かい再現はしない
