# 開いている画面とカーソル（2026-11-12）

オーナーの指示：入ったばかりでゲームメニューが開いているのをやめる。メニューの間は後ろを全部すりガラスにして、メニューのボタンのほかは押せなくする。マップを開いたときもカーソルを出す。ポップアップの × をなくす。チャットにスタンプを足し、背景をすりガラス・角は角にする。

## 前の作りで困ったこと

前は「カーソルが出ている＝ゲームメニュー」だった（`paused = !locked`）。そのため：

- ページを開いた直後はカーソルが出ている（ブラウザは、クリックなどの操作の中でしかカーソルを消させない）ので、必ずメニューが出ていた
- チャットを開くときにカーソルを出すと、メニューが出てしまうので、「チャット中はメニューを出さない」という例外を足していた。マップ・コレクション・ワープは、メニューの後ろの「押せるボタン」として開いていた
- メニューの間にまわりのボタンを押せる前提だったので、メニューを押せない面にすると、PC から下のボタン（コレクション・ワープなど）を押す方法が無くなる

## どうしたか

- **開いている画面を 1 つの値にした**（`overlay`：menu・map・chat・collection・warp・null）。PC では、何かを開くと自分でカーソルを出し（`exitLock`）、null に戻すとカーソルを消す（`requestLock`。閉じるクリック・キーの処理の中で呼ぶので、ブラウザが許す）
- **ゲームメニューは「操縦中に Esc でカーソルが戻ったとき」だけ出す**。自分で `exitLock` したときは、印（`quietUnlock`）を付けて区別する。入ったばかり・カーソルを消せなかったときは、何も開かず、照準の下に「クリックで操縦をはじめる」を出す
- カーソルが出ているときの Esc は、ページに届く。開いている画面を閉じる（何も開いていなければメニューを出す）。ただし、操縦中の Esc でカーソルが戻ったのと同じ Esc がページにも届くことがあるので、カーソルが戻ってから 0.3 秒の間の Esc は数えない
- **× の代わりに、まわりを押すと閉じる見えない面**を、マップ・コレクション・ワープの後ろに敷く。下のアイコンバーと情報のカードはその面より手前に出す（別の画面に切り替える・マップで選んだ天体の「その方を向く」を押すため）
- **1〜4 キーで下のボタン**を押せるようにした。メニューの間に下のボタンを押せなくなるため。マインクラフトのホットバーと同じく数字にした（ほかに使っていない）。メニューの間は、M・1〜4 で別の画面に切り替えない（メニューのボタンのほかは受け付けない、という指示に合わせた）
- Esc の直後は、ブラウザ（Chrome）がしばらくカーソルを消させない。そのときに「ゲームに戻る」を押すと、何も開いていないのにカーソルが出たままになるので、メニューに戻してお知らせを出す

## スタンプをチャットの中にした形

スタンプは「決まった文字のチャット」として送る。やりとりの形を足さずに済み、サーバーの確かめ方も 1 つのまま。前の「スタンプの id を送る」形（`isStampId`）には戻していない（チャットで自由な文が送れるので、id にする理由が無くなったため）。

## 確かめたこと

Chrome（WebGPU・ヘッドレス）の PC 1440×900 で：開いた直後はメニューが無く案内が出る → クリックでカーソルが消える → ページからカーソルを戻す（Esc の代わり）とメニューが出る → メニューの間に下のボタンの場所を押しても、1 キーを押しても何も開かない → 「ゲームに戻る」でカーソルが消える → 1 キーでコレクション（カーソルが出る）→ まわりのクリックで閉じてカーソルが消える → M でマップ → Esc で閉じて操縦に戻る → Enter → ☺ → 👋 で送って操縦に戻る。スマホの幅（390×844）で ☺・スタンプ・マップ（まわりのタップで閉じる）。本物の Esc キーでカーソルが戻る流れは、自動の確かめでは作れないので、人の手で確かめる必要がある。
