# 図鑑の絵を、天体ごとのデータに合わせる（2026-11-13）

## きっかけ

オーナーが図鑑の一覧を見て、「ほとんどの星の見た目が同じ。見た目のデータが無いのか」と聞いた。データはあった。要件 F38 で「恒星・星団・星雲・銀河・人工の物は、種類の形の絵」と決めていたので、色のほかは使っていなかった。

調べると、恒星のほかにも、持っているのに絵に使っていないデータがあった。

| 種類 | 持っていたデータ | それまでの絵 |
|------|------------------|--------------|
| 恒星 | 半径・温度・絶対等級・スペクトル型 | 色だけ違う、同じ大きさの丸 |
| 星雲 | 種類・半径 | 一覧は全部同じピンク（暗黒星雲も） |
| 銀河 | 型・傾き・軸の比・長軸の向き・明るさ | 一覧は全部同じ傾きの楕円。詳細は型で 3 通りだけ |
| 星団 | メンバーの数・広がり・年齢 | 散開か球状かの 2 通り |
| 彗星 | 核の直径・M1 | 全部同じ尾 |
| 白色矮星 | 温度 | 宇宙の中で、全部同じ青白 |

## 決まったこと（オーナー、2026-11-13）

選択肢は「A. データに合わせて描き分ける」「B. いまのまま、種類の形」。**A に決まった。**

## 判断

- **色を強めない**。本物の恒星の色は白〜うすいオレンジに収まるので、色だけでは違いが出にくい。色を強めれば違いは出るが、本物と変えることになる。大きさ・光の広がり・表面の模様で違いを出した
- **恒星の半径と温度は、宇宙の中の恒星と同じ関数（`starModel`）から取る**。図鑑だけ別の計算にすると、宇宙で見た大きさと食い違う。そのために `starModel` を外から使えるようにした
- **恒星の表面の模様は 4 通り**。太陽のほかの恒星の表面はほとんど観測できていないので、1 つずつは作れない。種類の傾向（外側に対流の層があるか・黒点の大きさ・巨星の巨大な対流）に合わせた
- **一覧の絵（星団・銀河・星雲・彗星）を CSS から canvas に変えた**。CSS のグラデーションでは、渦巻の腕や星の数を天体ごとに変えられない。詳細の絵と同じ点の集まりを、小さな canvas に 1 回だけ描く（回さないので、描くのは出したときだけ）。球と恒星は CSS のまま（→ 同じ日に、恒星も詳細と同じ球を canvas に描く形にした。一覧だけ模様の無いにじんだ丸で、詳細と見た目が違う、とオーナーに聞かれたため。CSS のまま残したことに、積極的な理由は無かった）
- **銀河の一覧の絵は、地球から見た向き**（観測の傾きと長軸の向き）。詳細は回せるので、最初の傾きだけ合わせた
- 形の分け方（楕円・渦巻・不規則）は、宇宙の中の銀河（`galaxyPoints`）と同じにした。それまで、型の分からない銀河は図鑑では渦巻、宇宙では不規則と、食い違っていた

## つまずいたこと

- **暗黒星雲がオレンジに光った**。点を足し合わせて明るくする描き方なので、茶色を濃く（0.35）重ねると明るいオレンジになる。前からあった不具合で、一覧に出して気づいた。濃さを 0.03 に下げた
- **渦巻銀河の一覧の絵が白く飛んだ**。小さな絵で星の点がつぶれないよう大きくすると、重なって真っ白になる。星の点だけ薄くした（銀河は 0.4 倍）
- `starColor` を白色矮星（`compact-objects.ts`）でも使おうとすると、`planets.ts` と互いに読み込む形になる。`star-color.ts` に分けた

## 手を付けなかったもの

- **小惑星の色**：JPL の表に反射率とスペクトル型があるが、いまは取り込んでいない（`npm run asteroids` の取り込みから変える必要がある）
- **宇宙の中の星団の、年齢による色**：作る星の決まりを変えることになるので、別に判断する
- **宇宙の中の恒星の表面**：どの恒星も同じ模様のまま（図鑑の 4 通りとは合っていない）
- パルサー・ブラックホール・人工衛星・探査機：絵を変えるデータが無い
