# 見た目の向上と、系外の衛星・環

## 決まったこと（オーナー、2026-11-05）

作業の前に論点をまとめて聞き、そのあと止まらずに作業した（要件 F25・F26）。

- 範囲：見た目の向上（恒星・大気・環の影）、系外の衛星と環、恒星系に入ったときの引っかかりを減らす改善
- 大気は、大気のある天体すべて（系外惑星を含む）
- 系外の衛星と環は、太陽系に近い割合
- **星団・星雲と恒星の種類（白色矮星など）は見送り**。距離の入った実データ（Gaia・ATNF・Harris・Cantat-Gaudin など）の配布元に、開発の環境から接続できなかったため。GitHub から取れる OpenNGC（CC BY-SA 4.0）は方向と大きさはあるが距離がほとんど無く、3 次元の場所に置けない
- ブランチは、前の作業がマージされた main から `feature/world-polish` を切った

## 系外の衛星を「作らない」としていた理由

前の作業では、作業の範囲を絞るために私（AI）が仮に置いた決まりだった。系外の衛星はまだ確実な観測が無く、割合の根拠が無かったため。オーナーに聞かれて、仮の決まりだったことを説明し、太陽系を手本にした割合で作ることにした。

## 惑星を変えずに衛星を足す

自動で作る惑星には世代の決まりがある（要件 F24：作り方を変えるなら新しい世代を足す）。衛星と環は、惑星を作る乱数とは別の乱数の流れで作り、惑星の id・大きさ・軌道には触れないようにした。足す前の 40 の恒星系・81 個の惑星の記録を取ってから作業し、足したあとも同じことをテストで確かめている。なので世代は 1 のまま。

## 環が真っ暗になった

北極の上から土星を見ると、環がほとんど見えなかった。2026 年の土星は春分（2025 年 5 月）の直後で、恒星の光が環の面にほぼ真横から当たる。ふつうの照明（ランバート）では、光の当たる角度の cos で明るさが決まるので、ほぼ 0 になる。現実でもこの時期の環は暗いが、見えないのは困るので、角度の平方根で弱め、最低 0.25 を残す自前の明るさにした。これで、本体の影が環の上に帯になって落ちるのも見えるようになった。

## 模様を描く時間

模様を描く時間を測ると、1 枚 512×256 で約 350 ms かかっていた（Node）。前の作業では描画のループと同じスレッドで描いていたので、太陽系の 8 天体で起動が数秒止まり、系外の恒星系に入るたびにも止まっていた。

- Web Worker に移し、描けるまでは灰色の仮の画像を貼るようにした
- ノイズの格子の値を求める関数で、可変長の引数の `hashInts` を呼んでいたのを書き下した（同じ値になることをテストで確かめた）。約 180 ms になった

## 試してやめたこと
