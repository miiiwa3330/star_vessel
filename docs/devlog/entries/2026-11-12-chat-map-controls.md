# チャット・マップ・キーボードの図

2026-11-12 のオーナーの指示（1 回のメッセージで 3 つ）：①「近く」を消し、マップ（レーダー）を押すと大きくなるように ②操作の説明を、キーボードの図に線が伸びて説明している形にし、タイトル画面の詳細にも出す ③スタンプをチャットにし、左下にチャット欄を足す。

## 前の決めを置き換えた

- **「自由な文字は送れない」（2026-11-05、F6）**を、オーナーの指示でやめた。前の理由は、荒らしや個人情報のやりとりを避けるためだった。その心配が消えたわけではないので、できる範囲で次のことを守り、残りは「決まっていないこと」に出した（ブロック・通報・言葉の絞り込み、宇宙船名を見せるか）
  - 文はサーバーに残さない（配るだけ）。残すと、個人情報を含む文の扱いを決める必要が出る
  - 届くのは、スタンプと同じ「船が見えている近くの人」だけ。恒星系の全員にはしなかった（知らない人に一斉に届く場にしないため）
  - 長さは 80 文字、1 秒に 1 回。制御文字と、文字の向きを変える記号（名前や文の見た目を入れ替えるなりすましに使われる）は消す
  - 名前は、ブラウザの言うことを信じず、Worker がログインの記録から読んで部屋に渡す（ブラウザから来た `x-user-name` は消す）
- **「近く」の一覧（F35）**をやめると、近くの恒星・星団・星雲・銀河を一覧から選べなくなる。マップはレーダーと同じ天体しか出さないため。照準の先・クリックでは、いままでどおり選べるので、それで足りると判断した
- 左上の切り替え（「スタンプ」「近く」）は、両方が無くなったので、切り替えごと消した

## チャットを PC の操縦と合わせる

- マインクラフトと同じく、Enter か T で入力欄を開く。カーソルを消して操縦している間は、入力欄をクリックできないため
- カーソルを出すとゲームメニューが出る作り（F60）なので、**先に「入力中」にしてからカーソルを出し**、入力中はゲームメニューを出さない。順番を逆にすると、一瞬メニューが出る
- T を押したとき、その「t」が開いたばかりの入力欄に入ってしまうので、キーの既定の動きを止める
- 入力欄の中のキーは、操縦に使わない。これが無いと、スマホでも「wasd」と打つと船が動く（キーは window で受けているため）

## キーボードの図の線の通し方

- 線が、説明のある（オレンジの）キーの上を通ると、どのキーの説明か分かりにくい。**キーの段と段の間の 4px のすき間を通して、キーボードの外へ出す**ことにした（例：W は下のすき間から左へ、D は上のすき間から右へ）
- 同じすき間を同じ向きに 2 本通すと重なって見分けられないので、1 つのすき間には、左へ 1 本・右へ 1 本まで。ここから、Q・W・A は左、E・D・S は右と決まった
- 大きな Space の上を線が通らないよう、C と M は、下のすき間で横の ⌘ のキーまで寄せてから下へ出す
- 狭い画面（タイトル画面のスマホ）では、図を縮めると文字が 5px くらいになって読めない。図は最小 720px の幅のまま、図だけ横にずらして見る（ページは横に動かない。390px で `scrollWidth` が 390 のままなのを確かめた）

## 画面で見つけたつまずき

- 大きくしたマップの名前が 1 文字しか出ず、白い大きな丸が出た
  - 名前：`#ui` の字間（`0.04em`）が px に直って SVG の文字に受け継がれ、SVG の単位（1 = レーダーの半径）で効いていた。0.64px の字間が、半径の 64% の字間になる
  - 白い丸：見えない「押せる範囲」の丸に、ホバーで白い線を付けていた。SVG の線の太さは、指定しないと 1（= 半径）
  - どちらも、レーダーの中の文字の字間・影を 0 にし、押せる範囲の丸には線を付けないようにして直した。小さなレーダーで起きなかったのは、字間を CSS で 0.003px と書いていたため（今回、文字の大きさを属性に移したときに消していた）
- 操作の図を開くと、ゲームメニューが上の情報のカードに重なった。図を開いている間は、カードを隠し、画面全体を暗くした

## 確かめたこと

- `npm run check`、テスト 326 件（チャットの文の決まりのテストを足し、スタンプのテストを消した）
- Chrome（WebGPU）で、PC 1440×900 の 2 つのブラウザ（別々のアカウント）：チャットが相手の左下に出る。マップを押すと大きくなり、点を押すと金星が選ばれ、上のカードとマップの輪がオレンジになる。M でマップを閉じる（ゲームメニューの間も）。「？ 操作」で図が出る
- スマホの幅（390×844・タッチ）：チャットの入力欄が十字のボタンとアイコンバーの上、マップは画面の上から出る
- タイトル画面の詳細の CONTROLS（PC・スマホ）
- WebGL2（WebGPU を消した状態）では見ていない（変えたのは画面の表示とサーバーのやりとりだけで、3D の描画には触れていない）
