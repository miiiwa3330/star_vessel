# 準備画面を無くす：UFO で船を選び、月でアカウント

仕様は [`../../product/top-screen.md`](../../product/top-screen.md)。要件は F48・F49・F50・F52・F55。

## 指示（オーナー）

- 「-START-」のあと、下へスクロールできなくし、名前を少し上げ、一言を消し、「-START-」を「GO」にし、地球と名前の間に UFO を置く
- UFO は 3 つ横に並べ、スライドで選ぶ。選んでいる 1 つだけ大きく、左右は小さい。画面の右から光の速さで飛んできたように出す
- 名前を押すとタイトルに戻る。戻るときは UFO が左へ消える
- いまの準備画面は完全に削除
- SIGN IN・SIGN UP を押したら月まで視点移動して箱を出し、終わったら地球に視点移動してタイトル画面

## 決めたこと（オーナーの指示で決まっていなかった部分。仮の判断）

- **3 つは輪にした**：選ぶ船が 3 種類で、いつも「左・真ん中・右」の 3 つが見えるようにするため。端の船を選ぶと片側が空く並びは、「3 つ横に並べて」から外れる。右へ送り続けると最初の船に戻る
- **URL は `/` のまま**：準備画面と一緒に `/ready` も無くした。船を選ぶ状態だけ、戻るボタンで戻れるよう履歴に足した
- **人数の表示は、場所が決まるまで出さない**：F50 の表示は準備画面にあった。オーナーの指示にないので、勝手に別の場所へ置かなかった（要件の「決まっていないこと」に推奨付きで残した）。サーバー側の数え方と `src/net/presence.ts` は残している
- **ユーザー名のボタンも月の箱を開く**：ログアウト・回復コードの作り直し・パスキーの追加は準備画面にあった。無くすと行き場がなくなるため、同じ箱を、ログイン中の画面で開く
- **「終わり」の定義**：ログインできた、または、登録して回復コードを保存して閉じた。回復コードが作れなかったときは終わりにせず、警告のある画面を見せる（見えなくなると作り直しに気づけないため）

## 作り方と理由

- **船は、地球と同じ GPU の画面に、地球のあとで重ねて描く**。前の準備画面の船のプレビューは、別の `WebGPURenderer` を持っていた。タイトル画面には、すでに地球の入れ物があるので、2 つ目を作らず、`autoClear` を切って深度だけ消し、2 枚目として描いた。1 ワールド単位 = 1 css px のカメラにして、DOM の箱（`.top-ufos`）の位置に合わせる。操作（スライド・タップ・キー）は、同じ場所に置いた見えない押せる範囲が受ける
- **箱が広がりきってから船を飛ばす**：一言が畳まれ、箱の高さが広がる間は、位置と大きさが変わり続ける。0.56 秒待ってから位置を教える。**消えるときは、箱が先に縮むので、最後に見えた位置を覚えて使う**（最初は忘れていて、船が一瞬で消えていた）
- **滑りはばね（臨界減衰）**：行き過ぎず、フレームの長さによらない。ドラッグは指に付け、離したら目標へ。**1 回で送るのは、始めた位置の隣まで**（最初は、いまの位置の隣までにしていて、1.15 個分引いたあとに勢いが付くと 2 つ先へ行った）
- **光の速さ**：飛来は `2^(-10t)` の形で、最初の 0.1 秒で距離の半分を進み、そのあと長く減速する。速い間だけ、後ろに光の筋（加算合成の細長い板を 3 本）を引く。背景が透明な画面への加算は、地球の大気と同じく、透明度を光の強さに合わせる
- **月へ飛ぶ**：月は、世界の画面と同じ画像・自転・太陽の向きで、本物の位置に置いた（地球から約 38 万 km なので、奥行きの範囲を 40 万から 100 万 km に広げた）。カメラは、地球のときと同じ見せ方（縁が画面の下に弧）の月のカメラへ、位置は直線で強く加速・減速、向きは遅れて回して混ぜる。帰りは、同じ進み具合を逆に戻すだけ。**飛行の進み具合は 0〜1 の 1 つの値**で、行きも帰りも、途中で向きを変えても飛ばない
- **星を流す**：直線で飛ぶと、真ん中の約 1.5 秒は、地球も月も見えず、真っ暗になった（最初に撮った画面）。画面に動きを足すため、星空（2D）の星を、画面の真ん中から外へ伸ばした。速さは位置の動き方の傾きから決める
- **船と月の準備は遅らせる**：どちらもシェーダーのコンパイルが要り、地球が現れる動きの間にやると引っかかる。地球の動きが終わってから済ませ、先に押されたらそのとき始める
- **3D が使えないとき**：船は出さず、押せる範囲に名前を文字で出して選べる。月へは飛ばず、箱をすぐ開く。月が準備できなかったときも同じ

## 確かめて見つけた不具合

- 船が左へ消えるとき、見えなくなっていた（上の「最後に見えた位置」）
- 「×」が、箱の見出しに隠れて押せなかった（Playwright の「他の要素が押下を受ける」で気づいた）
- スワイプで 2 つ先へ行った（上の「始めた位置の隣まで」）
- 確かめたことは top-screen.md の「準備画面を無くしたあと」

## 却下・やらなかったこと

- 船のプレビューを別の `WebGPURenderer` で描く（前の作り）：入れ物が 2 つになり、船を選ぶ画面で重い。重ねて描くのをやめる理由が出たら、戻す
- 月までの道を、地球・月を見たまま、向きを合わせ続ける作り：地球の向きがタイトルの船に依存して変わるので、道が複雑になる。直線＋星の流れで足りた
