# 星座と実データの追加

オーナーから「実データを元に作れる範囲で実装する」「星座を見られるボタンを足す」と頼まれた。

## 切り分け

作る前に、配布元に実際につないで確かめた。

| 対象 | 結果 |
|------|------|
| 星雲 | **作れる**。「距離の入った一覧が無い」として見送っていたが、SIMBAD の距離の測定値の表がハーバード大学のミラーから取れた |
| ほかの銀河 | 作れる（Updated Nearby Galaxy Catalog。距離が測定の値） |
| 彗星・探査機・仮符号の衛星 | 作れる（JPL） |
| 土星以外の環 | 作れる（NASA の Fact Sheet と論文） |
| いて座 A*・恒星の動き・系外惑星の不足 | 作れる（GRAVITY、HYG の速度、NASA Exoplanet Archive） |
| 地球の夜景と雲 | 作れる（Solar System Scope） |
| 星団の本物のメンバー | 作れる（Hunt & Reffert の表。約 130 万個） |
| 星の数の段差 | **一部だけ**。Gaia で範囲の中は増やせるが、1,000 pc の中の星をすべて持つのは無理 |
| 星の見えない距離帯・ハローの星 | **実データでは作れない**（カタログに無い）。モデルからの自動生成になるので、今回は入れない |
| 重力レンズ・本物の形の星雲 | データの問題ではない・画像の素材が要る |

## 判断

- **星座の線は 3 次元にする**：線の端を HYG の星に置き換えた。オーナーの「地球から見たらいい感じ、違う視点からも見られる」をそのまま満たす
- **`stars.bin` の形を変えない**：星の速度は別のファイル（`stars-motion.bin`）にした。`stars.bin` を読むツール（系外惑星の照合など）があるため。作り直した `stars.bin` が元と同じことも確かめた
- **星は起動のときに 1 回だけ動かす**：Barnard 星でも 1 秒に数百 km で、毎フレーム動かす必要が無い。ただし恒星系の惑星は恒星の位置についてくるので、ずれない
- **星雲と銀河の形は作る**：本物の形の素材は（ライセンスの点で）持っていない。位置・大きさなどは観測の値にして、カードに「形は作ったもの」と書く
- **仮符号の衛星は親の近くだけ**：天体の一覧に入れると毎フレーム計算して描くので、1 億 km 以内のときだけにした

## 試してやめたこと

- **`LineSegments2`（太さを選べる線）**：星座の線が画面を横切る太い帯になり、離れると消えた。ふつうの線にした
- **系外惑星を名前だけで照合**：KOI の番号と Kepler の番号など別の名前の同じ惑星が重複し、NASA の総数（6,451）より多い 6,847 個になった。恒星の方向と周期（1% 以内）でも照合して、283 個を重複として除いた
- **星雲の点の集まりを明るく**：地球の空に桃色の大きな塊が並んだ。面の明るさは距離で変わらないので、全体を暗くした
- **星雲の大きさの円の中を照準で選べるように**：大きな星雲が手前の彗星や惑星の名前を奪った。星雲・銀河は中心だけを選べるようにした

## つまずき

- **天王星に近づくと HUD が消えた**：座標の表示が `minimumFractionDigits` の範囲外で React ごと落ちた。原因は仮符号の衛星の軌道要素。S/2025 U 1 は Horizons の接触軌道要素が e=55,656、S/2023 S 38 は e=1.003 で、楕円の式で NaN になり、基準の天体の計算から自分の位置まで NaN になった。平均軌道要素の表の値に替え、全衛星が楕円であることをテストにした
- **系外惑星のテストが `main` でも落ちていた**：作った惑星の記録と最後の 1 桁だけ違う（`Math.cbrt` などの結果が Node の版で違う）。惑星の数や id は変わらないので、テストは数を 1e-12 の割合まで許す形にした
- **Gaia の配布元**：VizieR のミラーには Gaia の表の中身が無く、ハイデルベルク大学 ARI の TAP は全天の問い合わせが待ち行列から 30 分以上動かなかった。GAVO（`dc.g-vo.org`）の `gaia.dr3lite` は明るさで速く引け、`gcns.main` もあった。大きな応答は接続が切れることがあるので、明るさの幅ごとに分け、取り直すようにした
- **スマホでお知らせが画面を覆った**：`.hud-notice` の `top` が 2 か所にあり、スマホの `bottom` と両方効いて上下に伸びていた。前からの不具合で、お知らせはどれも同じだった

## 確かめたこと

テストと画面の詳細は、それぞれの docs（[`constellations.md`](../../tech/constellations.md)・[`nebulae.md`](../../tech/nebulae.md)・[`galaxies.md`](../../tech/galaxies.md)・[`spacecraft.md`](../../tech/spacecraft.md)）。今回は初めて、実際の GPU の WebGPU（Mac の Chromium）で見た。

## 残っていること

- 連星の軌道（ORB6 の表で作れるが、1 つの恒星系に 1 つの恒星という作りを変えることになる）
- 衛星の本物の地図・小惑星の本物の形・地球の細かい画像
- 銀河ごとの宇宙の住所（オーナーの決定が要る）
- 星の見えない距離帯とハローの星（モデルから作るかどうか）
