# タイトル画面の細かい直しと、クレジットの移動

[`2026-11-06-title-scroll.md`](2026-11-06-title-scroll.md) の続き。オーナーの指示は 7 つ。仕様は [`../../product/top-screen.md`](../../product/top-screen.md)、見た目の決めは [`../../design/README.md`](../../design/README.md)。

## したこと

| 指示 | したこと |
|---|---|
| 右上のアイコンは丸背景なし・ホバーで背景を付けない | 背景・ぼかし・角丸をやめた。ホバーはアイコンの透過の解除だけ |
| アイコンを少し透かし、ホバーで解除 | 不透明度 0.55 → ホバーで 1。明るい地球の上でも見えるよう、背景ではなく、形に沿った淡い影を付けた |
| 地球の画像の出典を、上の画面から削除 | 最初の画面から消した |
| 下の画面の出典を、Play 画面の記載事項とまとめ、Play 画面からは削除 | 詳細のいちばん下に「CREDITS」を作り、世界の画面の「クレジット」の中身を移した。世界の画面の「クレジット」のボタンと枠は消した |
| 下の画面の START はいらない | 消した |
| START はふだん薄く、ホバーで白 | 不透明度 0.42 の色 → ホバー・キー・指で白。ゆっくり明るさが変わる動きは、やめた |
| 一言を、英語表記に | 「Travel the same universe as players around the world.」（Josefin Sans の 300） |

## 判断したこと

- **クレジットは、移しただけで、内容は変えていない**。世界の画面の 12 項目をそのまま移し、書体（Monoton・Josefin Sans・OFL）の 1 行を足した。Solar System Scope は、世界の画面の「天体の画像」と、タイトル画面の「地球の画像」の 2 つあったので、「地球・天体の画像」の 1 行にまとめた。データは `src/top/Credits.tsx` の 1 か所（同じ数を 2 か所に持たない）
- **「Play 画面の記載事項」は、クレジットのことと受け取った**。「？ 操作」（操作の説明）は残した。違っていたら、言ってもらう
- **準備画面の下の 1 行（地球の画像）は、そのまま残した**。「上の画面から削除」の指示にも、準備画面は入っていなかったため。背景の地球が、この画像を使っているので、表記が無い画面を作らないほうを選んだ。まとめたいなら、消せる
- **一言を英語にしたので、日本語の細字の問題はなくなった**。日本語の細い書体は、端末で細さが違った。英語の Josefin Sans は、どの端末でも同じ

## 注意（ライセンス）

**世界の画面（`/play`）から出典が消えた**。`/play` を直接開く（ブックマーク・共有された URL）と、出典を見られない。HYG・Gaia・OpenNGC・SatNOGS は CC BY-SA、Solar System Scope は CC BY で、媒体に合った妥当な方法での表記を求める。タイトル画面の詳細で足りるかは、公開の前に確かめる。足りない（または、不安）なら、世界の画面に、「CREDITS」（`/#credits`）へのリンクを 1 つ置く案がある（出典の「情報」ではなく、リンクだけなので、オーナーの指示と両立する）。オーナーに伝えて、判断を待つ。
