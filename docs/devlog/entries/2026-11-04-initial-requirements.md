# 最初の要件の整理

## 決めたこと

オーナーから受けた説明と、論点ごとの回答を要件にした（[`../../product/requirements.md`](../../product/requirements.md)）。

- 一人称で宇宙を探索する。同時に遊んでいる全世界のプレイヤーは宇宙船として見える。全員が地球から出発し、銀河の規模まで行ける
- 天体は実世界に忠実にし、軌道・自転・公転を現実の時刻に合わせる
- 他のプレイヤーとの交流は、あいさつ・スタンプ程度にする（推奨案を採用）
- 遊びの要素は後で考える。まずは世界の創造から作る

## 「実世界に忠実」と「リアルすぎなくていい」

最初の説明では「リアルすぎなくていい（重いので）」、論点への回答では「実世界に忠実にしたい」とあった。食い違いではなく、対象が違うと整理した。

- **位置と動き**は本物にする。軌道の計算は軽いので、重さの心配がない
- **見た目**は写実に寄せすぎない。重くなるのはこちら

この整理を、コンセプトの「世界観の方針」に書いた（[`../../concept/README.md`](../../concept/README.md)）。

## 本物に合わせられないもの

- **移動の速さ**：距離が本物なので、光の速さでも銀河は渡れない。移動のしかた（速さの切り替え・ワープ）は未定
- **データの無い範囲**：距離が精度よく分かる星は銀河のごく一部。銀河の大部分は自動で生成することになる

## 提供形態はまだ決めない

オーナーが「処理的に可能な範囲を知りたい」としたため、決める前に Web とネイティブアプリでどこまでできるかを調べた（[`../../tech/feasibility.md`](../../tech/feasibility.md)）。今の要件は Web で処理として十分に可能で、差が出るのは地表に降りる・VR などの今は無い要件だった。
