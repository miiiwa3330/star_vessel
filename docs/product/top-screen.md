# タイトル画面と準備画面

世界（操縦席）の前に出す 2 つの画面。サービスの入口。要件は [`requirements.md`](requirements.md) の F48〜F53（2026-11-06）。見た目の決まりは [`../design/README.md`](../design/README.md)。

## 流れ

```
タイトル画面（/） → 画面をタップ → 準備画面（/ready） →「出発する」→ 世界（/play）
```

- オーナーの指示（2026-11-06）：**タイトル画面と準備画面は分ける**。世界は Top では描かない（独立したページ）
- 世界（`/play`）は、約 78 MB のデータを読んで動く。タイトル画面と準備画面は世界を読み込まず、軽く開く（本番ビルドで、文字が出るまでに読むのは約 100 KB（書体 2 つ分を含む）。そのあと、背景の 3D の地球と船のために、three.js と画像などを遅れて読む。くわしくは下の「読み込み」）
- `/play` を直接開いてもよい（これまでどおり、匿名で自動ログインして始まる）。ブックマークや、`?asteroids=bright` のような確かめ用の指定を付けた URL が使える。出発するときは、いまの URL の `?` 以降を世界に引き継ぐ
- 世界からタイトル画面・準備画面へ戻る入口は、まだ無い（URL を開き直す）

## タイトル画面（要件 F48・F53）

景色が主役で、文字は最小限。2026-11-06 にオーナーの指示で作り直した。

- **文字**：名前（STAR VESSEL）・一言・「-START-」だけ。**枠のあるボタンは置かない**。**画面のどこをタップ（クリック）しても、Enter・Space を押しても、次へ進む**（Ctrl・Alt・Cmd つきは進まない）。「-START-」はゆっくり明るさが変わる。読み上げとキーボード（Tab）のため、本物のボタンも 1 つ置いてある（見た目は枠なしの文字）
- **名前の書体と色**：**Monoton（OFL）をオレンジ**（`#ff8a1f`、光のにじみつき）にする。オーナーが指定した（2026-11-06。Google Fonts の貼り付けを 4 通り受け取ったが、どれも外のサーバーから読み込む書き方なので、同じ書体を自分のサーバーから配る形にした）。細い線を重ねた、ネオンの管のような書体。幅が広いので、大きさは画面の幅の 11%（最大 112px）で、どの幅でも 1 行に収まる。「-START-」は、細い Josefin Sans（OFL）のまま
  - 最初は、オーナーが添付した画像（虹色に光るガラス調の四つ角の星のマーク。文字は入っていない）の質感を、Josefin Sans の文字を虹色に塗って再現した。オーナーが書体と色を指定したので、置き換えた（経緯は [devlog](../devlog/entries/2026-11-06-title-ui.md)）
- **いま遊んでいる人数は出さない**（準備画面に出す）
- **背景**：星空（2D）と、**いまの時刻の本物の地球**（3D）。画像は世界の画面と同じ（昼・夜の灯り・雲）で、自転の向きも太陽の向きも本物。日本の夜景は、いま夜の側にあれば見える。大気の光の縁もある。地球が出るまでの間（と、3D が使えないとき）は、前からある CSS の地球の縁を出し、描けたらゆっくり入れ替える
- **本物の船**：太陽系の宇宙の部屋で、地球から約 100 万 km 以内にいる本物のプレイヤーの船が、光の点（色はその人の船の色）と、進んできた向きの短い尾で出る（要件 F53）。2 秒ごとに読み直し、位置は速度のまま進め、食い違いは少しずつ消すので、飛んで見えない。現れる・消えるときは 1 秒かけて明るさを変える。**誰もいなければ地球だけ**（作り物の船は出さない）
- **カメラ**：地球の縁が画面の下に弧を描き、その上に船が浮かぶ向きへ、ゆっくり動く（船を追う遅れは約 4 秒。船は画面の中を動いて見える）。船がいなければ、昼と夜の境目が見える向きで、ごくわずかに揺れる。船が複数いれば、地球に近い船を見て、その船がいる間は見続ける。「動きを減らす」の設定では揺れと追従を止め、1 秒に 1 回だけ描く
- **読み込み**：本番ビルドで、文字は 3D を待たずに出る（速い回線で約 0.13 秒、4G で約 0.5 秒、遅い 4G で約 2 秒）。3D の地球が出るのは、速い回線で約 0.9 秒、4G で約 3.3 秒、遅い 4G で約 15 秒。転送は合計約 2 MB（画像 1.6 MB・JS 319 KB・フォント 28 KB）。画像は世界の画面と同じなので、そのあと世界を開くときは、ブラウザが覚えている。**重いと感じたら、事前に描いた画像 1 枚に切り替える**（オーナーの決め。URL に `?earth=css` を付けると、いまでも CSS の縁だけになり、約 85 KB。通信量を節約する設定（Save-Data）のときも、そうなる）
- **出典の 1 行**：画面の下の端に、「地球の画像：Solar System Scope（CC BY 4.0）」を小さく出す（CC BY の表記）。押しても進まない

## 準備画面（要件 F48）

- **いま遊んでいる人数**（要件 F50）：見出しの下に「いま N 人が旅をしています」。0 人なら「いま旅をしている人は、いません」。読めなければ何も出さない。30 秒ごとに読み直す。**タイトル画面では出さない**（2026-11-06）ので、ここに置いた。置き場所は仮
- **背景**：タイトル画面と同じ（3D の地球と本物の船）。カードの後ろに見える
- **宇宙船**：3 種類の船体から選ぶ。選んだ船を、ゆっくり回して見せる（世界の画面と同じ形のモデル。色はアカウントから決まる）。保存してある船があればそれを、なければアカウントから決まる船を最初に選んでおく
- **アカウント**：下の「アカウント」
- **出発する**：選んだ船が保存してあるものと違うときだけ保存してから、世界へ。サーバーにつながらないときは、保存せずに出発できる
- 開いたとき、登録なしのアカウントを作る（船の色がアカウントで決まるので、本当の色で見せるため。どのみち出発すれば作る）。**タイトル画面を見るだけでは作らない**（見るだけの人のアカウントが増えないように）

## アカウント（要件 F14・F49）

- 登録しなくても遊べる（F14）。端末を変えても記録を残したい人だけ、準備画面から登録する
- **方式はユーザー名＋パスワード**（2026-11-06）。オーナーの候補は「Google ログイン・パスキー・一意のユーザー名とパスワード」だった。手元で確かめられ、外のサービスの設定も個人情報（メール）も要らないものから作った。Google ログインとパスキーは、まだ入れていない（[`requirements.md`](requirements.md) の「決まっていないこと」）
- ユーザー名：英数字と `_` の 3〜20 文字。大文字小文字は区別しない（保存は小文字、表示は入力のまま）。パスワード：8〜64 文字（`src/world/account.ts`）
- **メールアドレスは集めない**。忘れたときは、下の「回復コード」で戻す
- 登録・ログインのとき、**匿名のときの記録を引き継ぐ**：ワープホール（全部。登録した側がすでに持っていて 3 個を超えても消さない。新しく置けなくなるだけ）・宇宙船の設計（登録した側がすでに決めていればそちら）・訪れた天体（合わせる。同じ天体は早い方の日時）。仕組みは [`../tech/server.md`](../tech/server.md) の「アカウント」
- ログアウトすると匿名に戻る（次に世界を開くと、新しい匿名のアカウントで始まる）

## 回復コード（要件 F51）

ユーザー名やパスワードを忘れたときに戻すためのもの。メールを集めないので、これが復旧の手段になる。

- **作るとき**：登録のあと、コードの画面が自動で開く（`XXXXX-XXXXX-XXXXX-XXXXX` の 20 文字）。コピーとファイルへの保存ができる。「保存しました」にチェックするまで閉じられない（Esc でも閉じない）。閉じると二度と見られない
- **ユーザー名を忘れた**：「ログイン」→「ユーザー名やパスワードを忘れたとき」でコードを入れると、ユーザー名が分かる。「このユーザー名でログインする」で、ログインの欄に入る。**コードは使い切らない**
- **パスワードも忘れた**：同じ画面で新しいパスワードを決める。ほかの端末のログインはすべて切れ、使ったコードは無効になり、新しいコードの画面が開く。そのままログインした状態になる（匿名のときの記録も引き継ぐ）
- **作り直す**：ログインしていれば、準備画面から作り直せる（前のコードは無効になる）。他人に触られても変えられないよう、パスワードを求める。登録の直後に通信が切れてコードが作れなかったときは、「回復コードがありません」と出て、ここから作れる
- 入力は、小文字・空白・ハイフンの有無を問わない。見間違えやすい文字（O・I・L）は 0・1 として読む
- **回復コードも無くすと、戻す方法は無い**（入力の画面にそう書く）
- **最後のユーザー名**：この端末で最後に使ったユーザー名を覚えて、ログインの欄に入れておく（ユーザー名は秘密ではないので端末に置く。パスワードは覚えない）。名前だけを忘れた場合の多くは、これで足りる

## パスキー（要件 F52）

- **足す**：登録してログインしたあと、準備画面の「この端末のパスキーを追加」。端末ごとに足す。端末の一覧には、ユーザー名が出る
- **ログイン**：「ログイン」→「パスキーでログイン」。ユーザー名もパスワードも入れない（ユーザー名を忘れていても入れる）。匿名のときの記録も引き継ぐ
- **消す**：一覧の「消す」→「本当に消す」
- 自分で途中でやめたときは、エラーを出さない
- パスワードと併用する。パスキーだけでは登録できない。匿名のアカウントには、画面から足せない
- **足せるのはログインから 1 日以内**（Better Auth の既定。回復コードと違ってパスワードは求めない）。過ぎていると「一度ログアウトして、もう一度ログインしてから」と出る
- 回復コードでパスワードを決め直しても、パスキーは残る。一覧を見て、知らないものがあれば消す
- **いまの穴**：パスキーでは入れるが、パスワードも回復コードも無くした人は、回復コードを作り直せない（パスワードが要るため）。遊ぶことはできる

## 仮のもの

- 名前・一言・「-START-」「出発の準備」などの文言（一言は、これまでの `index.html` の説明と同じ）
- 見た目（星空・地球・虹色の文字）の細部。デザインの方向性は、まだ全体では決まっていない
- 船体の名前（F27 のとおり仮）
- 回復コードの形（1 人 1 つを作り直せる形。8 個を一度に出す形もある）

## 確かめたこと（2026-11-06）

- Playwright で本物の GPU の Chromium を開き、PC（1280×720・1000×760）とスマホ（390×844）の幅で、タイトル → 準備 → 登録 → 出発 → 世界まで通した。WebGPU と WebGL2（`navigator.gpu` を消した状態）の両方で、船のプレビューが描けることを見た
- 登録で、短いパスワード・使えない文字・すでにあるユーザー名（大文字小文字違いを含む）・間違ったパスワードの日本語のエラーが出る
- 別の端末（別のブラウザの状態）で、同じアカウントにログインして、船が引き継がれていること。ログアウトで匿名に戻ること
- 3 種類の船を選んで登録 → 出発し、選んだ船が保存されること（WebGPU・WebGL2）
- 人数：実際の WebSocket で、3 接続（2 つの部屋）→ 3 人、1 つ閉じて 2 人、0 人の部屋が増えても合計が合う、70 秒後に行の時刻が書き直される、全部閉じると 0 人で行が消える
- 回復コード（画面）：登録 → コードの画面（閉じるは無効・Esc で閉じない・後ろを触れない）→ コピー・ファイルの中身 → 保存 → 閉じる → 作り直し（間違ったパスワードは断る）→ ログアウト → 最後の名前が入る → コードを入れて名前が分かる（小文字・空白でも読む。作り直す前のコードは断る）→ このユーザー名でログイン → パスワードの決め直し → 新しいコードの画面のままログインする（チェックが消えない）→ 別のブラウザで古いパスワードは断られ、新しいパスワードで入れる。スマホの幅（390px）でコードがはみ出さない
- 回復コード（API）：匿名は作れない・形の違うコードと違うコードを断る・もとの端末のログインが切れる・同時に 2 回送っても片方だけ効く
- パスキー：Chrome の仮想の認証器（開発者ツールの WebAuthn の機能）で、追加 → 同じ端末でもう一度（断られる）→ 途中でやめる（エラーなし）→ ユーザー名を入れずにログイン（匿名の記録も移る）→ 回復コードで決め直してもログインできる → ログインから時間がたつと足せない → 消す → サーバーで消した鍵では入れない。**本物の端末（iPhone の Face ID など）と、端末をまたぐ同期では、まだ確かめていない**
- タイトル画面（2026-11-06 の作り直し）：枠のあるボタンが無い・人数が出ない・「-START-」の文字・書体が Monoton でオレンジ。幅 360〜1920px のすべてで、名前が 1 行に収まり、横スクロールが出ない。画面の何もない場所をクリック・Enter・Space・Tab → Enter・「-START-」の文字のクリックで、いずれも 1 回だけ進み、戻る 1 回でタイトル画面に戻る。Ctrl+Enter では進まない。スマホの幅（390px）でタップして進む
- 本物の船：`tools/sim-ships.mjs` で、本物のプレイヤーと同じ通信（匿名ログイン → 宇宙の部屋の WebSocket）の船を 4 隻出し、タイトル画面で、光の点と尾が見え、動くことを確かめた。WebGPU（60 fps）と WebGL2（`navigator.gpu` を消した状態）の両方。`/api/earth-ships` が 503 を返しても 3D の地球は出て、ページのエラーは出ない。準備画面でも、背景の地球と船のプレビューが両方描ける。カメラが船を追う動きは、数枚の画面と、船の位置の計算のテストで確かめた（長い時間の連続した動きを、動画では確かめていない）
- 本番ビルドを `vite preview` で配り、`/`・`/ready`・`/play`・知らない URL が index.html を返し、`/api/` は Worker が返すこと
