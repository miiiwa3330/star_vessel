# タイトル画面

世界（操縦席）の前に出す画面。サービスの入口。要件は [`requirements.md`](requirements.md) の F48〜F55（2026-11-06）。見た目の決まりは [`../design/README.md`](../design/README.md)。

## 流れ

```
タイトル画面（/）
  ├ 「-START-」→ 船を選ぶ（同じ画面の中の状態）→「-Go!-」→ 世界（/play）
  │    └ 名前（STAR VESSEL）を押す・Esc・ブラウザの戻る → タイトルへ戻る（船は左へ消える）
  ├ SIGN IN・SIGN UP → カメラが月まで飛ぶ → アカウントの箱
  │    └ ログイン・登録が終わる・「×」・Esc → カメラが地球へ戻る → タイトル
  └ ユーザー名（サインインしているとき、SIGN IN・SIGN UP の代わりに出る）→ カメラが火星まで飛ぶ → ユーザー情報の箱
       └ サインアウト・「×」・Esc → カメラが地球へ戻る → タイトル
```

- オーナーの指示（2026-11-06）：**準備画面（`/ready`）は無くした**。船を選ぶのも、アカウントも、タイトル画面の中の状態にした。URL は `/` のまま（船を選ぶ状態だけ、ブラウザの戻るで戻れるよう、履歴に 1 つ足す）。`/ready` を開くと、タイトル画面が出る。世界は Top では描かない（独立したページ）
- 世界（`/play`）は、約 78 MB のデータを読んで動く。タイトル画面は世界を読み込まず、軽く開く（本番ビルドで、文字が出るまでに読むのは約 100 KB（書体 2 つ分を含む）。そのあと、背景の 3D の地球と船のために、three.js と画像などを遅れて読む。くわしくは下の「読み込み」）
- `/play` を直接開いてもよい（これまでどおり、匿名で自動ログインして始まる）。ブックマークや、`?asteroids=bright` のような確かめ用の指定を付けた URL が使える。出発するときは、いまの URL の `?` 以降を世界に引き継ぐ
- 世界からタイトル画面へ戻る入口は、まだ無い（URL を開き直す）

## 船を選ぶ（要件 F48。2026-11-06 にオーナーの指示で作った。前の準備画面の船の選択の代わり）

「-START-」を押すと、タイトル画面が次の状態になる（`src/top/TopApp.tsx` の段階 `select`）：

- **スクロールできなくなる**（下の詳細は隠す。ホイール・キー・スワイプのどれでも動かない）
- **名前（STAR VESSEL）が少し上がり、一言が消える**（一言の行が畳まれるので、名前が自然に上へ動く）。名前を押す（または Esc・ブラウザの戻る）と、タイトルに戻る。名前は、マウスを乗せると光が強くなる
- **「-START-」が「-Go!-」に変わる**（同じボタン。枠は無く、文字だけ。マウスを乗せると水色にうっすら光る。2026-11-06 にオーナーの指示で、丸い枠の「GO」から変えた）。**少し下げて、地球の縁の近くに置く**（画面の高さの 7% 分。同じ日に、さらに下げた）。**色は「-START-」と同じ**（ふだんは薄く〈不透明度 0.42〉、マウスを乗せる・キーで選ぶ・指で押すと白。2026-11-06 に、光のにじみを付けていたのをやめて、そろえた）。押すと出発する
- **地球と名前の間に、宇宙船（UFO）が横に 3 つ並ぶ**。3 つは輪になっていて、右へ送り続けても最初の船に戻る。**真ん中の 1 つだけ大きく（直径は箱の高さの 95%・幅の 36% の小さい方。PC で約 250px）、左右の 2 つは半分の大きさ**（同じ日に、大きくした）。**船の間隔は、箱の幅の 37%**（箱は幅の 96%・最大 760px。PC で、船と船の間が約 90px あく。最初は 32% で、約 20px しかあかなかった）。**列は、少し下へ下げた**（画面の高さの 4.5%）。間隔の数は、3D の船と押せる範囲で同じもの（`ufo-carousel.ts` の `SPACING_OF_WIDTH`）形は世界の画面と同じ 3 種類（ソーサー・ベル・リング。名前は仮）、色はアカウントから決まる（読めるまでは仮の色）
- **選び方**：横に引く（スライド。指でもマウスでも。離したあと、勢いがあれば先まで滑るが、1 回で送るのは隣まで）／左右の船をタップ／左右の矢印キー／横のスクロール（トラックパッド）。滑りはばねで、行き過ぎない。引いている間は、船が動く向きに少し傾く
- **出るとき：画面の右から光の速さで飛んでくる**。最初は速く、減速して止まる。速い間は、船の後ろ（右）に光の筋を引く。左の船から順に 0.13 秒ずつ遅れて出る。箱が広がりきってから（約 0.56 秒後）飛んでくる
- **戻るとき：左の画面へ消えていく**。ゆっくり動き出し、加速して左へ消える。光の筋は後ろ（右）。左の船から順に。消えてから、一言が戻る
- 初めに選んでいる船：保存してあるものがあればそれ、なければアカウントから決まる船（世界の画面の最初の選択と同じ）。「-START-」を押したときに読み込む（登録なしのアカウントは、ここで作る。**タイトル画面を見るだけでは作らない**）。自分で選んだあとは、読み込んだ船で上書きしない
- **-Go!-**：選んだ船が保存してあるものと違うときだけ保存してから、世界へ。サーバーにつながらないときは、保存せずに出発できる。保存に失敗したときは、「宇宙船を保存できませんでした」と出て、選び直せる
- **仕組み**：船は、地球と同じ GPU の画面（`earth-scene.ts`）に、地球のあとで重ねて描く（`ufo-layer.ts`）。画面の位置は、DOM の箱（`UfoPicker.tsx` の `.top-ufos`）に合わせる（1 ワールド単位 = 1 css px のカメラ）。操作は、同じ場所に置いた 3 つの見えない押せる範囲（左・真ん中・右。`role="radio"`・船の名前の `aria-label`）が受ける。**計算は純粋な関数に切り出してテストしてある**（`ufo-carousel.ts`：並び・大きさ・ばね・出入り）。画面の部品と描画は、`top-stage.ts` の入れ物で受け渡す
- **3D が使えないとき**（`?earth=css`・通信量の節約・描けなかったとき）は、船は出ず、3 つの押せる範囲に、船の名前の文字が出る（選んでいる船は水色で太字）。「動きを減らす」の設定では、飛んでくる・滑る・回る・傾くを止め、止まった位置にすぐ出る
- 準備を先に済ませる：地球が現れる動きが終わって約 1 秒後に、船の 3D の準備（モデルとシェーダー）を始める。「-START-」が先に押されたら、そのとき始める

## 月と火星：アカウントの箱（要件 F49・F55。2026-11-06 にオーナーの指示）

右上の SIGN IN・SIGN UP を押すと**月**へ、サインインしているとき代わりに出るユーザー名を押すと**火星**へ飛ぶ。どちらも同じ作り（行き先の天体と、箱の中身だけが違う）：

1. 文字と右上のボタンが消え、**カメラが月（または火星）まで飛ぶ**（約 2.2 秒。最初は 3.6 秒だったが、同じ日に、オーナーの指示で短くした）。**「月ー地球ー火星」の並びで、いつも「前へ飛ぶ」**（`earth-camera.ts` の `forwardLeg`。2026-11-06 にオーナーの指示で、本物の位置を使う飛び方から変えた）：3 つの天体は、いまのカメラが見ている向きの 1 本の線に並ぶ。**カメラは、向きを変えず、見ている向きへ、まっすぐ進む**（見上げる・見下ろすの揺れ〈ウェーブ〉がない）。**いまの天体は、そのまま画面の下へ消え**（約 0.4 秒かけて落ちる）、**次の天体は、画面の奥の真ん中に小さな点として現れて大きくなり**（画面の上から出てこない）、最後に、遠近法だけで中心から下へ動いて、地球のときと同じ構図（縁が画面の下に弧）で落ち着く。**地球 → 月、地球 → 火星、月 → 地球、火星 → 地球は、すべて同じ動き**（時間を逆に再生するのではなく、戻るときも前へ飛ぶ）。飛んでいる間、**星が画面の真ん中から外へ伸びて流れる**（光の速さ。2D の星空に描く）。船を選んでいる最中なら、船は左へ消える
2. **着くと、箱が開く**（`AuthBox.tsx`）。月・火星は、地球のときと同じ見せ方（縁が画面の下に弧を描く。カメラは天体の中心から半径の約 1.7 倍）。画像・自転の向きは世界の画面と同じ（`2k_moon.jpg`・`2k_mars.jpg`）。**位置と太陽の向きは、本物ではなく、見た目のための配置**：カメラが進む距離は、どれも 200 万 km（月も火星も同じ。本物は、月 38 万 km・火星 5,600 万〜4 億 km で、月と火星で動きが変わってしまうため）。太陽の向きは、地球と同じ（月・火星も、地球のときと同じ位置に昼夜の境目が見える）。**そのため、タイトル画面の空に、本物の月が小さく見えることは、なくなった**
3. 箱の中身は、前の準備画面のアカウントの部品そのもの（`AccountPanel.tsx`）。**月の箱**：登録・ログイン・回復コード。SIGN IN で開くとログインの入力、SIGN UP で開くと登録の入力が最初から開く（ユーザー名の欄に、この端末で最後に使った名前が入る）。**火星の箱（ユーザー情報）**：ユーザー名（大きく）・「でサインインしています」・回復コードの状態と作り直し・パスキーの追加と一覧・**サインアウトのボタン**（区切り線の下。2026-11-06 に「ログアウト」から言い方を変えた）。**サインアウトすると、箱が閉じて地球へ戻り、右上が SIGN IN・SIGN UP に戻る**
4. **終わると、カメラが地球へ戻り（同じ時間・同じ道）、タイトル画面が出る**。「終わり」は：サインアウトしたとき（火星の箱）／ログインできたとき／パスキーでログインできたとき／**登録して回復コードの画面を閉じたとき**（コードが作れなかったときは、終わりにせず、「回復コードがありません」の画面を見せる）／パスワードを決め直して回復コードの画面を閉じたとき。**「×」・Esc・「やめる」でも、同じように戻る**（回復コードの画面が開いている間の Esc は、そちらの決まり。保存するまで閉じない）。戻ったあと、右上の表示が読み直される（ユーザー名／SIGN IN・SIGN UP）
5. 箱を開いたとき、登録なしのアカウントを作る（匿名のときの記録を、登録・ログインのときに移すため。カメラが飛んでいる間に読み込む）
6. 月へ飛ぶ間もスクロールはできない。詳細まで下がっていたら、最初の画面の位置へ戻してから飛ぶ
7. **3D が使えないとき**は、飛ばずに、すぐ箱が開く。火星の画像は、**サインインしていると分かったら、地球が現れて約 7 秒後に先読みする**（押してから読むと、動き出しが遅れ、読み込みで引っかかるため。月は約 5 秒後）。3D の読み込みが終わらないまま 7 秒たったときも、箱を開く。地球へ戻る途中で描画が止まっても、8 秒で戻す
8. 月の画像の読み込みとシェーダーの準備は、船より少し遅れて（地球が現れて約 5 秒後）、先に済ませておく。準備できなかったら（月・火星とも）、飛ばずに箱を開く

## タイトル画面（要件 F48・F53・F54）

縦に 2 つの画面が並ぶ（船を選ぶ間と月にいる間は、スクロールできず、詳細は隠れる）：**最初の画面**（景色が主役）と、スクロールした先の**サービスの詳細**。2026-11-06 にオーナーの指示で作り直した。

### 最初の画面

- **文字**：名前（STAR VESSEL）・一言・「-START-」だけ。**枠のあるボタンは置かない**。**「-START-」のまわり（約 330×110px）をタップ（クリック）すると、次へ進む**（画面全体のタップは、詳細をスクロールで読めるようにするため、やめた）。「-START-」は、**ふだんは薄い色で、マウスを乗せる（キーで選ぶ・指で押す）と白くなる**。キーボードは、Tab で「-START-」に移って Enter。どこにも焦点が無いときの Enter でも進む（Space は、スクロールに使う）
- **名前の書体と色**：**Monoton（OFL）をオレンジ**（`#ff8a1f`、光のにじみつき）にする。オーナーが指定した（2026-11-06。Google Fonts の貼り付けを 4 通り受け取ったが、どれも外のサーバーから読み込む書き方なので、同じ書体を自分のサーバーから配る形にした）。細い線を重ねた、ネオンの管のような書体。幅が広いので、大きさは画面の幅の 11%（最大 112px）で、どの幅でも 1 行に収まる。「-START-」は、細い Josefin Sans（OFL）
  - 最初は、オーナーが添付した画像（虹色に光るガラス調の四つ角の星のマーク。文字は入っていない）の質感を、Josefin Sans の文字を虹色に塗って再現した。オーナーが書体と色を指定したので、置き換えた（経緯は [devlog](../devlog/entries/2026-11-06-title-ui.md)）
- **一言は、英語の細字**：「Travel the same universe as players around the world.」（Josefin Sans の 300。オーナーの指示で、日本語の「地球から飛び立ち、世界中のプレイヤーと同じ宇宙を旅する。」の後半を、英語表記にした。日本語の細字は、細い字のない端末で太くなる問題があったが、英語にしたので、どの端末でも細い）
- **いま遊んでいる人数は出さない**（準備画面を無くしたので、出す場所は、いまは無い。[`requirements.md`](requirements.md) の「決まっていないこと」）
- **右下のアイコン**：X（https://x.com/miiiwa3330）と Miiiwa（https://miiiwa.com）。押すと、新しいタブで開く（`rel="noopener noreferrer"`）。**2026-11-06 に、右上から右下へ移した**（オーナーの指示）。スクロールしても、右下に残る。**丸い背景は付けず、ふだんは透かし（不透明度 0.55）、マウスを乗せたアイコンだけ、透過を解く**（アイコン自体の色の変化だけ）。明るい地球の上でも見えるよう、背景ではなく、アイコンの形に沿った淡い影を付ける。X は、X のロゴの形。Miiiwa は、オーナーのロゴ（オレンジの 3 つの点と 3 本の縦棒の「iii」）で、もとの黒い棒を、暗い背景のために明るい色にした。どちらも図形だけの SVG（画像のファイルは読み込まない）
- **右上の SIGN IN・SIGN UP**（要件 F55。2026-11-06 にオーナーの指示）：「-START-」と同じく、ふだんは薄く（不透明度 0.62）、マウスを乗せると白。SIGN UP だけ細い枠を付ける（丸い背景は付けない）。押すと、**カメラが月まで飛び、アカウントの箱が、ログイン（または登録）の入力の状態で開く**（上の「月とアカウントの箱」）。登録したアカウントでログインしているときは、2 つのボタンの代わりに、**ユーザー名**を出し、押すと、**カメラが火星まで飛び、ユーザー情報の箱が開く**（サインアウト・回復コード・パスキー）（匿名のアカウントは、ログインに数えない。サーバーに 1 回だけ問い合わせる。Better Auth のクライアントは読み込まない）
- **背景**：星空（2D）と、**いまの時刻の本物の地球**（3D）。画像は世界の画面と同じ（昼・夜の灯り・雲）で、自転の向きも太陽の向きも本物。夜の側には、本物の街の灯りが見える。大気の光の縁もある
  - **仮の球体は出さない**（2026-11-06 にオーナーの指示）。読み込み中は、星空だけ。描ける状態（画像の読み込み・描画の準備・シェーダーのコンパイルが終わった状態）になってから、地球が**画面の下から約 1.6 秒かけて上がってきて、同時にゆっくり現れる**。前にあった CSS の球体は、3D を使わないとき（通信量の節約・`?earth=css`）と、3D が描けなかったときだけ出る
- **本物の船**：太陽系の宇宙の部屋で、地球から約 100 万 km 以内にいる本物のプレイヤーの船が、光の点（色はその人の船の色）と、進んできた向きの短い尾で出る（要件 F53）。2 秒ごとに読み直し、位置は速度のまま進め、食い違いは少しずつ消すので、飛んで見えない。現れる・消えるときは 1 秒かけて明るさを変える。**誰もいなければ地球だけ**（作り物の船は出さない）
- **カメラ**：地球の縁が画面の下に弧を描き、その上に船が浮かぶ向きへ、ゆっくり動く（船を追う遅れは約 4 秒）。船がいなければ、昼と夜の境目が見える向きで、ごくわずかに揺れる。船が複数いれば、地球に近い船を見て、その船がいる間は見続ける。「動きを減らす」の設定では、揺れ・追従・現れる動きを止め、1 秒に 1 回だけ描く
- **読み込み**：本番ビルドで、文字は 3D を待たずに出る（速い回線で約 0.13 秒、4G で約 0.5 秒、遅い 4G で約 2 秒）。3D の地球が出るのは、速い回線で約 0.9 秒、4G で約 3.3 秒、遅い 4G で約 15 秒。転送は合計約 2 MB（画像 1.6 MB・JS 319 KB・フォント 28 KB）。画像は世界の画面と同じなので、そのあと世界を開くときは、ブラウザが覚えている。**重いと感じたら、事前に描いた画像 1 枚に切り替える**（オーナーの決め）
- **出典**：最初の画面には出さない。詳細のいちばん下の「CREDITS」にまとめた（下の「サービスの詳細」）。準備画面の下にあった、地球の画像の 1 行は、準備画面と一緒に無くした

### スクロール

- 最初の画面と詳細の間は、**止まらない**。指のスクロール（スマホ）とキーボード（Space・PageDown・Home）は、どちらかの画面の先頭へ吸い付く（CSS の `scroll-snap`・`mandatory`・`stop: always`）。**マウスのホイールとトラックパッドは、最初の画面と詳細の中のどちらも、1 つの動きで動かす**（`src/top/section-scroll.ts`。2026-11-06 にオーナーの指摘で直した。それまでは詳細の先頭で約 0.3〜0.6 秒止まり、そのあとカクついていた）：
  - **速さの上限は 1200px/s**（オーナーの指示。どれだけ強く回しても超えない）。回転量は 0.8 倍にして、少し遅くしてある。行き先を今の位置より約 300px 以上先に置かないので、手を止めれば、すぐ止まる
  - **動きには慣性がある**：行き先へ引く力とブレーキ（臨界減衰のばね。強さ 8 rad/s）で、行き過ぎず、なめらかに減速する。2 つの画面の間では、回した強さが動き出しの速さになり（250〜1200px/s）、約 1.5 秒で収まる。速くなるときの加速にも上限がある（7000px/s²）
  - **最初の画面で少し回すと、1 回で詳細の先頭まで動く**。1 回の操作（フリック）の余韻は、詳細の先頭で受け止める（500px 分）ので、軽く回せば、詳細の先頭で止まる
  - **続けて回すと、止まらずに通り過ぎる**：新しい操作（間が 0.12 秒以上空いた・向きが変わった・減っていた回転量がまた増えた）か、受け止める量を超えて回し続けると、詳細の先頭で止まらず、そのまま詳細の中へ進む。上へも同じで、詳細の中から回し続けると、そのまま最初の画面まで戻る
  - 動いている途中で逆向きに回すと（画面の間では 30px 以上）、いまの速さのまま向きを変える。動いている間だけ、CSS の吸い付きを切る。背景の地球は、スクロールの位置に毎フレーム追従する。「動きを減らす」の設定では、動かさずに、一度に移る
- 詳細が 1 画面より長いので、**詳細の中は自由に止まれる**（そこでは吸い付かない）。詳細の先頭で上へ回すと、最初の画面へ戻る

- 詳細の文字は、地球の下の縁より下から始める（余白は画面の高さの 46%）

## 回復コード（要件 F51）

ユーザー名やパスワードを忘れたときに戻すためのもの。メールを集めないので、これが復旧の手段になる。

- **作るとき**：登録のあと、コードの画面が自動で開く（`XXXXX-XXXXX-XXXXX-XXXXX` の 20 文字）。コピーとファイルへの保存ができる。「保存しました」にチェックするまで閉じられない（Esc でも閉じない）。閉じると二度と見られない
- **ユーザー名を忘れた**：「ログイン」→「ユーザー名やパスワードを忘れたとき」でコードを入れると、ユーザー名が分かる。「このユーザー名でログインする」で、ログインの欄に入る。**コードは使い切らない**
- **パスワードも忘れた**：同じ画面で新しいパスワードを決める。ほかの端末のログインはすべて切れ、使ったコードは無効になり、新しいコードの画面が開く。そのままログインした状態になる（匿名のときの記録も引き継ぐ）
- **作り直す**：ログインしていれば、ユーザー名のボタン（月の箱）から作り直せる（前のコードは無効になる）。他人に触られても変えられないよう、パスワードを求める。登録の直後に通信が切れてコードが作れなかったときは、「回復コードがありません」と出て、ここから作れる
- 入力は、小文字・空白・ハイフンの有無を問わない。見間違えやすい文字（O・I・L）は 0・1 として読む
- **回復コードも無くすと、戻す方法は無い**（入力の画面にそう書く）
- **最後のユーザー名**：この端末で最後に使ったユーザー名を覚えて、ログインの欄に入れておく（ユーザー名は秘密ではないので端末に置く。パスワードは覚えない）。名前だけを忘れた場合の多くは、これで足りる

## パスキー（要件 F52）

- **足す**：登録してログインしたあと、ユーザー名のボタン（月の箱）の「この端末のパスキーを追加」。端末ごとに足す。端末の一覧には、ユーザー名が出る
- **ログイン**：「ログイン」→「パスキーでログイン」。ユーザー名もパスワードも入れない（ユーザー名を忘れていても入れる）。匿名のときの記録も引き継ぐ
- **消す**：一覧の「消す」→「本当に消す」
- 自分で途中でやめたときは、エラーを出さない
- パスワードと併用する。パスキーだけでは登録できない。匿名のアカウントには、画面から足せない
- **足せるのはログインから 1 日以内**（Better Auth の既定。回復コードと違ってパスワードは求めない）。過ぎていると「一度ログアウトして、もう一度ログインしてから」と出る
- 回復コードでパスワードを決め直しても、パスキーは残る。一覧を見て、知らないものがあれば消す
- **いまの穴**：パスキーでは入れるが、パスワードも回復コードも無くした人は、回復コードを作り直せない（パスワードが要るため）。遊ぶことはできる
