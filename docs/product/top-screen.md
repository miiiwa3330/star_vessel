# タイトル画面と準備画面

世界（操縦席）の前に出す 2 つの画面。サービスの入口。要件は [`requirements.md`](requirements.md) の F48〜F54（2026-11-06）。見た目の決まりは [`../design/README.md`](../design/README.md)。

## 流れ

```
タイトル画面（/） →「-START-」をタップ → 準備画面（/ready） →「出発する」→ 世界（/play）
```

- オーナーの指示（2026-11-06）：**タイトル画面と準備画面は分ける**。世界は Top では描かない（独立したページ）
- 世界（`/play`）は、約 78 MB のデータを読んで動く。タイトル画面と準備画面は世界を読み込まず、軽く開く（本番ビルドで、文字が出るまでに読むのは約 100 KB（書体 2 つ分を含む）。そのあと、背景の 3D の地球と船のために、three.js と画像などを遅れて読む。くわしくは下の「読み込み」）
- `/play` を直接開いてもよい（これまでどおり、匿名で自動ログインして始まる）。ブックマークや、`?asteroids=bright` のような確かめ用の指定を付けた URL が使える。出発するときは、いまの URL の `?` 以降を世界に引き継ぐ
- 世界からタイトル画面・準備画面へ戻る入口は、まだ無い（URL を開き直す）

## タイトル画面（要件 F48・F53・F54）

縦に 2 つの画面が並ぶ：**最初の画面**（景色が主役）と、スクロールした先の**サービスの詳細**。2026-11-06 にオーナーの指示で作り直した。

### 最初の画面

- **文字**：名前（STAR VESSEL）・一言・「-START-」だけ。**枠のあるボタンは置かない**。**「-START-」のまわり（約 330×110px）をタップ（クリック）すると、次へ進む**（画面全体のタップは、詳細をスクロールで読めるようにするため、やめた）。「-START-」はゆっくり明るさが変わる。キーボードは、Tab で「-START-」に移って Enter。どこにも焦点が無いときの Enter でも進む（Space は、スクロールに使う）
- **名前の書体と色**：**Monoton（OFL）をオレンジ**（`#ff8a1f`、光のにじみつき）にする。オーナーが指定した（2026-11-06。Google Fonts の貼り付けを 4 通り受け取ったが、どれも外のサーバーから読み込む書き方なので、同じ書体を自分のサーバーから配る形にした）。細い線を重ねた、ネオンの管のような書体。幅が広いので、大きさは画面の幅の 11%（最大 112px）で、どの幅でも 1 行に収まる。「-START-」は、細い Josefin Sans（OFL）
  - 最初は、オーナーが添付した画像（虹色に光るガラス調の四つ角の星のマーク。文字は入っていない）の質感を、Josefin Sans の文字を虹色に塗って再現した。オーナーが書体と色を指定したので、置き換えた（経緯は [devlog](../devlog/entries/2026-11-06-title-ui.md)）
- **一言は細字**：font-weight 200。日本語の細い書体は端末にあるもの（Hiragino Sans・游ゴシック・Noto Sans JP）を使う（Web フォントは足していない）。細い字がない端末では、ふつうの太さになる
- **いま遊んでいる人数は出さない**（準備画面に出す）
- **右上のアイコン**：X（https://x.com/miiiwa3330）と Miiiwa（https://miiiwa.com）。押すと、新しいタブで開く（`rel="noopener noreferrer"`）。スクロールしても、右上に残る。明るい地球の上でも見えるよう、うっすら暗い丸を敷く。X は、X のロゴの形。Miiiwa は、オーナーのロゴ（オレンジの 3 つの点と 3 本の縦棒の「iii」）で、もとの黒い棒を、暗い背景のために明るい色にした。どちらも図形だけの SVG（画像のファイルは読み込まない）
- **背景**：星空（2D）と、**いまの時刻の本物の地球**（3D）。画像は世界の画面と同じ（昼・夜の灯り・雲）で、自転の向きも太陽の向きも本物。夜の側には、本物の街の灯りが見える。大気の光の縁もある
  - **仮の球体は出さない**（2026-11-06 にオーナーの指示）。読み込み中は、星空だけ。描ける状態（画像の読み込み・描画の準備・シェーダーのコンパイルが終わった状態）になってから、地球が**画面の下から約 1.6 秒かけて上がってきて、同時にゆっくり現れる**。前にあった CSS の球体は、3D を使わないとき（通信量の節約・`?earth=css`）と、3D が描けなかったときだけ出る
- **本物の船**：太陽系の宇宙の部屋で、地球から約 100 万 km 以内にいる本物のプレイヤーの船が、光の点（色はその人の船の色）と、進んできた向きの短い尾で出る（要件 F53）。2 秒ごとに読み直し、位置は速度のまま進め、食い違いは少しずつ消すので、飛んで見えない。現れる・消えるときは 1 秒かけて明るさを変える。**誰もいなければ地球だけ**（作り物の船は出さない）
- **カメラ**：地球の縁が画面の下に弧を描き、その上に船が浮かぶ向きへ、ゆっくり動く（船を追う遅れは約 4 秒）。船がいなければ、昼と夜の境目が見える向きで、ごくわずかに揺れる。船が複数いれば、地球に近い船を見て、その船がいる間は見続ける。「動きを減らす」の設定では、揺れ・追従・現れる動きを止め、1 秒に 1 回だけ描く
- **読み込み**：本番ビルドで、文字は 3D を待たずに出る（速い回線で約 0.13 秒、4G で約 0.5 秒、遅い 4G で約 2 秒）。3D の地球が出るのは、速い回線で約 0.9 秒、4G で約 3.3 秒、遅い 4G で約 15 秒。転送は合計約 2 MB（画像 1.6 MB・JS 319 KB・フォント 28 KB）。画像は世界の画面と同じなので、そのあと世界を開くときは、ブラウザが覚えている。**重いと感じたら、事前に描いた画像 1 枚に切り替える**（オーナーの決め）
- **出典の 1 行**：最初の画面の下の端に、「地球の画像：Solar System Scope（CC BY 4.0）」を小さく出す（CC BY の表記）。詳細の最後と準備画面にも出す

### スクロール

- 最初の画面と詳細の間は、**止まらない**。どちらかの画面の先頭へ、吸い付くように動く（CSS の `scroll-snap`・`mandatory`・`stop: always`）。マウスのホイールは、少し回しただけでも、1 回で隣の画面へ動く（`src/top/section-scroll.ts`。ブラウザの吸い付きは「近い方」へ戻ることがあるため）。トラックパッドの余韻は、動かしたあと 0.7 秒捨てる。指のスクロール（スマホ）とキーボード（Space・PageDown・Home）は、ブラウザの吸い付きに任せる
- 詳細が 1 画面より長いので、**詳細の中は自由にスクロールできる**（そこでは吸い付かない）。詳細の先頭で上へ回すと、最初の画面へ戻る
- スクロールで、**背景の地球が動く**：カメラが地球から離れ（約 1.8 倍）、見る向きを上へ振るので、**最初の画面では地球の上の縁が画面の下に見え、詳細の先頭では、地球の下半分が画面の上に見える**（地球の中心が画面の上の端のすぐ上。下の縁が、画面の上から約 4 割の高さ）。詳細より先へ進むと、地球はページと一緒に、画面の上へ出ていく
- 詳細の文字は、地球の下の縁より下から始める（余白は画面の高さの 46%）

### サービスの詳細（要件 F54）

スクロールした先に、サービスの説明を書く。**文章は仮**（オーナーの確認待ち。[`requirements.md`](requirements.md) の「決まっていないこと」）。書いてあることは、[コンセプト](../concept/README.md)（体験の核・世界観の方針）と、README・要件のできること・データの数から。

- ABOUT：一言と、サービスの説明。体験の核 4 つ（一人称で宇宙を進む・本物の宇宙がいま動いている・ひとりじゃない・みんな地球から始まる）
- REAL DATA：本物のデータの数（星 約 100 万個・小惑星 約 90 万個・系外惑星 約 6,600 個・人工衛星 約 1,700 機・星団 約 6,900 個など）。遠くは光の点、近づくと実際の大きさ
- PLAY：できること（宇宙船を選ぶ・ワープホールを置く・天体を調べる・星座をたどる）
- ACCOUNT：登録しなくても始められる。メールアドレスは集めない
- いまは「世界の創造」の段階で、操縦などは仮のものと書く
- 最後に、もう一度「-START-」を置く（読み終わったあと、そのまま進めるように）。
- **数は、実際に入っているデータの数**（README.md）。データが増えたら、`src/top/ServiceDetails.tsx` の数も直す

## 準備画面（要件 F48）

- **いま遊んでいる人数**（要件 F50）：見出しの下に「いま N 人が旅をしています」。0 人なら「いま旅をしている人は、いません」。読めなければ何も出さない。30 秒ごとに読み直す。**タイトル画面では出さない**（2026-11-06）ので、ここに置いた。置き場所は仮
- **背景**：タイトル画面と同じ（3D の地球と本物の船）。カードの後ろに見える
- **宇宙船**：3 種類の船体から選ぶ。選んだ船を、ゆっくり回して見せる（世界の画面と同じ形のモデル。色はアカウントから決まる）。保存してある船があればそれを、なければアカウントから決まる船を最初に選んでおく
- **アカウント**：下の「アカウント」
- **出発する**：選んだ船が保存してあるものと違うときだけ保存してから、世界へ。サーバーにつながらないときは、保存せずに出発できる
- 開いたとき、登録なしのアカウントを作る（船の色がアカウントで決まるので、本当の色で見せるため。どのみち出発すれば作る）。**タイトル画面を見るだけでは作らない**（見るだけの人のアカウントが増えないように）

## アカウント（要件 F14・F49）

- 登録しなくても遊べる（F14）。端末を変えても記録を残したい人だけ、準備画面から登録する
- **方式はユーザー名＋パスワード**（2026-11-06）。オーナーの候補は「Google ログイン・パスキー・一意のユーザー名とパスワード」だった。手元で確かめられ、外のサービスの設定も個人情報（メール）も要らないものから作った。Google ログインとパスキーは、まだ入れていない（[`requirements.md`](requirements.md) の「決まっていないこと」）
- ユーザー名：英数字と `_` の 3〜20 文字。大文字小文字は区別しない（保存は小文字、表示は入力のまま）。パスワード：8〜64 文字（`src/world/account.ts`）
- **メールアドレスは集めない**。忘れたときは、下の「回復コード」で戻す
- 登録・ログインのとき、**匿名のときの記録を引き継ぐ**：ワープホール（全部。登録した側がすでに持っていて 3 個を超えても消さない。新しく置けなくなるだけ）・宇宙船の設計（登録した側がすでに決めていればそちら）・訪れた天体（合わせる。同じ天体は早い方の日時）。仕組みは [`../tech/server.md`](../tech/server.md) の「アカウント」
- ログアウトすると匿名に戻る（次に世界を開くと、新しい匿名のアカウントで始まる）

## 回復コード（要件 F51）

ユーザー名やパスワードを忘れたときに戻すためのもの。メールを集めないので、これが復旧の手段になる。

- **作るとき**：登録のあと、コードの画面が自動で開く（`XXXXX-XXXXX-XXXXX-XXXXX` の 20 文字）。コピーとファイルへの保存ができる。「保存しました」にチェックするまで閉じられない（Esc でも閉じない）。閉じると二度と見られない
- **ユーザー名を忘れた**：「ログイン」→「ユーザー名やパスワードを忘れたとき」でコードを入れると、ユーザー名が分かる。「このユーザー名でログインする」で、ログインの欄に入る。**コードは使い切らない**
- **パスワードも忘れた**：同じ画面で新しいパスワードを決める。ほかの端末のログインはすべて切れ、使ったコードは無効になり、新しいコードの画面が開く。そのままログインした状態になる（匿名のときの記録も引き継ぐ）
- **作り直す**：ログインしていれば、準備画面から作り直せる（前のコードは無効になる）。他人に触られても変えられないよう、パスワードを求める。登録の直後に通信が切れてコードが作れなかったときは、「回復コードがありません」と出て、ここから作れる
- 入力は、小文字・空白・ハイフンの有無を問わない。見間違えやすい文字（O・I・L）は 0・1 として読む
- **回復コードも無くすと、戻す方法は無い**（入力の画面にそう書く）
- **最後のユーザー名**：この端末で最後に使ったユーザー名を覚えて、ログインの欄に入れておく（ユーザー名は秘密ではないので端末に置く。パスワードは覚えない）。名前だけを忘れた場合の多くは、これで足りる

## パスキー（要件 F52）

- **足す**：登録してログインしたあと、準備画面の「この端末のパスキーを追加」。端末ごとに足す。端末の一覧には、ユーザー名が出る
- **ログイン**：「ログイン」→「パスキーでログイン」。ユーザー名もパスワードも入れない（ユーザー名を忘れていても入れる）。匿名のときの記録も引き継ぐ
- **消す**：一覧の「消す」→「本当に消す」
- 自分で途中でやめたときは、エラーを出さない
- パスワードと併用する。パスキーだけでは登録できない。匿名のアカウントには、画面から足せない
- **足せるのはログインから 1 日以内**（Better Auth の既定。回復コードと違ってパスワードは求めない）。過ぎていると「一度ログアウトして、もう一度ログインしてから」と出る
- 回復コードでパスワードを決め直しても、パスキーは残る。一覧を見て、知らないものがあれば消す
- **いまの穴**：パスキーでは入れるが、パスワードも回復コードも無くした人は、回復コードを作り直せない（パスワードが要るため）。遊ぶことはできる

## 仮のもの

- 名前・一言・「-START-」「出発の準備」などの文言と、サービスの詳細の文章（オーナーの確認待ち）（一言は、これまでの `index.html` の説明と同じ）
- 見た目（星空・地球・虹色の文字）の細部。デザインの方向性は、まだ全体では決まっていない
- 船体の名前（F27 のとおり仮）
- 回復コードの形（1 人 1 つを作り直せる形。8 個を一度に出す形もある）

## 確かめたこと（2026-11-06）

- Playwright で本物の GPU の Chromium を開き、PC（1280×720・1000×760）とスマホ（390×844）の幅で、タイトル → 準備 → 登録 → 出発 → 世界まで通した。WebGPU と WebGL2（`navigator.gpu` を消した状態）の両方で、船のプレビューが描けることを見た
- 登録で、短いパスワード・使えない文字・すでにあるユーザー名（大文字小文字違いを含む）・間違ったパスワードの日本語のエラーが出る
- 別の端末（別のブラウザの状態）で、同じアカウントにログインして、船が引き継がれていること。ログアウトで匿名に戻ること
- 3 種類の船を選んで登録 → 出発し、選んだ船が保存されること（WebGPU・WebGL2）
- 人数：実際の WebSocket で、3 接続（2 つの部屋）→ 3 人、1 つ閉じて 2 人、0 人の部屋が増えても合計が合う、70 秒後に行の時刻が書き直される、全部閉じると 0 人で行が消える
- 回復コード（画面）：登録 → コードの画面（閉じるは無効・Esc で閉じない・後ろを触れない）→ コピー・ファイルの中身 → 保存 → 閉じる → 作り直し（間違ったパスワードは断る）→ ログアウト → 最後の名前が入る → コードを入れて名前が分かる（小文字・空白でも読む。作り直す前のコードは断る）→ このユーザー名でログイン → パスワードの決め直し → 新しいコードの画面のままログインする（チェックが消えない）→ 別のブラウザで古いパスワードは断られ、新しいパスワードで入れる。スマホの幅（390px）でコードがはみ出さない
- 回復コード（API）：匿名は作れない・形の違うコードと違うコードを断る・もとの端末のログインが切れる・同時に 2 回送っても片方だけ効く
- パスキー：Chrome の仮想の認証器（開発者ツールの WebAuthn の機能）で、追加 → 同じ端末でもう一度（断られる）→ 途中でやめる（エラーなし）→ ユーザー名を入れずにログイン（匿名の記録も移る）→ 回復コードで決め直してもログインできる → ログインから時間がたつと足せない → 消す → サーバーで消した鍵では入れない。**本物の端末（iPhone の Face ID など）と、端末をまたぐ同期では、まだ確かめていない**
- タイトル画面（2026-11-06 の作り直し）：枠のあるボタンが無い・人数が出ない・「-START-」の文字・書体が Monoton でオレンジ。幅 360〜1920px のすべてで、名前が 1 行に収まり、横スクロールが出ない。Ctrl+Enter では進まない
- タイトル画面（2026-11-06 の 2 回目）：
  - 仮の球体：読み込み中の DOM を 25 ms ごとに見て、CSS の球体が 1 回も出ないこと、3D の canvas は、描ける状態になるまで不透明度 0 のままなこと。描ける状態になってから、地球の縁が、画面の外（下）から 687px → 589 → 532 → 505 → 495px と上がってくること（WebGPU・WebGL2・「動きを減らす」・タブレット・小さいスマホ（360×640）のすべてで、仮の球体は出ない）
  - スクロール：ホイールを 4・40・100・300・800px 回したどれでも、1 回で詳細の先頭（720px）へ動き、戻らず、なめらかに増える。余韻のように 6 回続けて回しても、詳細の先頭で止まる。詳細の先頭で上へ 40px で、最初の画面へ戻る。詳細の中は、下へ 400px・上へ 400px で、先頭までしか戻らない。Space・Shift+Space・PageDown・Home で、2 つの画面の先頭へ動く。指で 150px スワイプでは最初の画面に戻り、500px では詳細の先頭へ動く（スマホの幅）
  - タップ：「-START-」の真ん中・上 50px・右 165px は進む。上 70px・右 200px は進まない。画面の左上・名前の文字・地球の上は進まない
  - 右上のアイコン：リンク先（`https://x.com/miiiwa3330`・`https://miiiwa.com/`）・`target="_blank"`・`rel="noopener noreferrer"`。X を押すと、新しいタブが開き、タイトル画面は進まない（このサンドボックスは外へ出られないので、開いた先の表示は確かめていない）
