## 決めたこと（2026-11-12。オーナーの答え）

- 入れる範囲は**名前のある実在の天体**（自動で作った星は無限にあるので入れない）
- まだ訪れていない天体は、**名前を「？？？」にし、詳細は種類とだいたいの場所だけ**
- 説明の文は、**データから作る文に加え、主な天体は AI が書く**（出典を docs に残す）
- 番号は**全部を通しの 1 本**（No.00001 から）

- 数は、データを作り直すと変わる。上の数は図鑑の見出しの「/ 26,216」と同じ

## 番号の付け方

- 先に太陽系を、決まった順に並べる：太陽 → 水星 → 金星 → 地球・月 → 火星とその衛星 → … → 海王星とその衛星 → 冥王星とその衛星 → 小惑星・準惑星（軌道の大きい順ではなく、小さい順）→ 彗星（周期彗星は番号の順、そのほかは近日点を通る日の順）→ 探査機
- そのあとに、太陽系の外を**太陽から近い順**に並べる。恒星のすぐ後ろに、その恒星の惑星を並べる（データの順＝恒星に近い順）
- 同じ記号が 2 度出たら、先のものだけを残す（固有名のある恒星が系外惑星の恒星でもあるとき、惑星付きの方を残すため、系外惑星の恒星を先に入れる）
- 番号はデータから決まるので、誰の端末でも同じ。データを作り直すと、途中に天体が増えて番号がずれることがある（いまの制限）

## 詳細に出すもの

訪れた天体（上から順に）：

1. **解説**（AI が書いた文）。書いたのは、太陽・惑星・主な衛星・主な小惑星と準惑星・探査機 18 機すべて・主な彗星・明るい恒星・近い恒星・系外惑星の有名なもの・いて座 A* と主なパルサー・名前のある星団・星雲・銀河（約 140）。**どの天体にも、その種類の説明を続けて付ける**（恒星とは・系外惑星とは、など）
2. **数の表**：種類ごとにデータから作る
   - 太陽・惑星・月・冥王星：NASA の表の質量・密度・重力・脱出速度・温度・気圧・1 日の長さ・自転の軸の傾き・衛星の数・環・磁場、軌道（平均の距離・近日点・遠日点・周期・速さ・傾き・離心率）
   - そのほかの太陽系の天体：半径、軌道の大きさ・周期・離心率・傾き（ケプラーの軌道の要素）、自転
   - 彗星：近日点の距離・離心率・遠日点・周期・近日点を通る日・核の直径
   - 恒星：固有名・符号・星座・スペクトル型・表面の温度・半径と質量（系外惑星のデータにあるとき）・光度（絶対等級から）・見かけの等級・惑星の一覧
   - 系外惑星：主星・軌道の大きさ・周期・離心率・半径・質量・温度
   - パルサー：自転の周期・1 秒に回る回数。ブラックホール：質量・事象の地平面の半径
   - 星団：メンバーの数・半数半径・潮汐半径・年齢。星雲：種類・半径。銀河：種類・半径・明るさ・傾き
   - **いまの位置**（どの天体も）：太陽から・地球から・光でかかる時間・地球から見た方向（赤経・赤緯）
3. **くらべてみると**（計算から作る文）：体重 50 kg の人が感じる重さ、その天体の 1 年、地球何個分の大きさ、光が出た年、など
4. **記録**：はじめて訪れた日

まだ訪れていない天体：番号・種類・「？？？」と、**場所**（太陽系の天体は「木星のまわり」「太陽から約 5.2 天文単位」、太陽系の外は「太陽から約 X 光年・〇〇座の方向」〈星座は HYG の恒星だけ。ほかは赤経・赤緯〉）。「その方を向く」で、その天体の方を向ける（探しに行けるように）。

## 出典

- **太陽・惑星・月・冥王星の数**：NASA Goddard Space Flight Center「Planetary Fact Sheet - Metric」（https://nssdc.gsfc.nasa.gov/planetary/factsheet/ 、最終更新 2025-03-18）と「Sun Fact Sheet」（https://nssdc.gsfc.nasa.gov/planetary/factsheet/sunfact.html）。2026-11-13 に取得し、表の値をそのまま写した（丸めていない）。太陽の表面の温度 5,772 K は IAU 2015 の公称値（`src/world/planets.ts` の T_SUN と同じ）
- **恒星の固有名・符号・スペクトル型・見かけの等級・星座**：HYG v4.4（CC BY-SA 4.0）。`public/data/star-info.json` と `star-info.LICENSE.txt`
- **恒星の日本語の名前**：広く使われているカタカナの読み（国立天文台「理科年表」などの書き方に合わせた）。`STAR_NAMES_JA` に約 80 個
- **星座の日本語の名前**：`public/data/constellations.json`（[`constellations.md`](constellations.md)）
- **そのほかの数**：それぞれのデータの出典（[`credits.md`](credits.md)）。光度は絶対等級から L = 10^(−0.4 (M − 4.83))（放射補正は無視）、色から温度は Ballesteros の式（`teffFromBv`）、ブラックホールの事象の地平面の半径は 2.953 km × 太陽質量の倍数
- **解説の文**：AI（Claude）が、広く知られている事実から書いた。数値は確かなものだけを入れ、くわしい数は表に任せた。確かめに使う資料：NASA Science の各天体のページ、NASA/JPL・ESA・JAXA のミッションのページ、国立天文台「理科年表」。**人の目での確認はまだ**。書いたあとに、自信の持てなかった 4 か所（フォボスの大きさ、エンケ彗星の周期の書き方、池谷・張彗星の年、系外惑星の数）を直した

## 詳細の回せる絵

- three.js は使わず、2D の canvas に 1 画素ずつ描く（`renderGlobe`）。宇宙の描画（WebGPU）と取り合わず、天体 1 つ（340 px 四方）なら 1 回 数 ms。ひとりでに回っている間は毎フレーム描く
- **球**：正射影。見る向き（yaw・pitch）で回した球の 1 点ずつを、地図（横 2：縦 1）の経度・緯度にして色を取る。光は左上の手前から。恒星は影を付けず、ふちを少し暗くする。大気はふちのにじみ（ふちと、にじみの間に透けた筋ができないよう、色をつなぐ）
- **環・円盤**：赤道の面と視線の交わり。球より手前の部分だけ球の上に描く。球の影に入る部分は暗くする。ブラックホールは黒い球と、光るオレンジの円盤
- **点の集まり**：星団（球状星団はプラマーの分布、散開星団はまばら）・銀河（ふくらみと 2 本の渦巻の腕。楕円銀河はふくらみだけ）・星雲（種類ごとの色。惑星状星雲・超新星残骸は殻）・彗星（核と尾）。種（記号から）で決まるので、いつも同じ形。**見た目のための形で、観測の形ではない**
- 画像は 1024×512 に縮めて読み、模様は 512×256 で描く（同じものは 1 回だけ）
- ドラッグで回し、離すと少し滑ってから、ゆっくりひとりでに回る（毎秒 0.22 ラジアン。動きを減らす設定では、ひとりでには回らない）
- まだ訪れていない天体は、同じ形を CSS の `brightness(0)` で黒くし、ふちをうっすら光らせる

## 確かめたこと（2026-11-13）

- テスト：カタログの並べ方・番号・重なり（`src/world/catalog.test.ts`）、回す向き・地図の位置・球と環・点の並び（`src/ui/globe-render.test.ts`）
- 画面（Chrome の WebGPU、PC 1440×900・スマホ 390×844、WebGL2）：見出しが「6 / 26,216」、1,748 ページ。地球・月・火星・太陽・TRAPPIST-1 が絵で、ほかは黒いシルエットと「？？？」。火星を押すと、一覧の場所（幅 76 px）から詳細の場所（幅 340 px）へ 0.5 秒で滑り、戻ると一覧の場所へ戻る（位置を 80 ms ごとに測った）。ドラッグで北極が見える向きまで回る。説明は 1,700 px ほどでスクロールする。土星（環）・オメガ星団・M43・アンドロメダ銀河・いて座 A*・かにパルサーを訪れて、詳細の絵を見た
- 図鑑を初めて開くまで（カタログを作る）：PC で約 70〜140 ms
- 確かめていない：本物のスマホでの回し心地、iPhone の Safari

## いまの制限

- データを作り直すと、番号がずれることがある
- 彗星・小さな衛星の多くは、日本語の名前が無い（英語の名前のまま）
- パルサーの絵は恒星と同じ（光の筋は描いていない）
- 解説の文は人の目で確かめていない
