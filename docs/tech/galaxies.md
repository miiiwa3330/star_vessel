# 銀河（天の川銀河の外）

コードは `src/world/galaxies.ts`（読み方・形を作る）、`src/render/extragalactic-view.ts`（描画）、`tools/build-galaxies.mjs`（データ）。

## データ

| 項目 | 内容 |
|------|------|
| 一覧 | Karachentsev ほか (2013), AJ 145, 101「Updated Nearby Galaxy Catalog」（VizieR J/AJ/145/101、ハーバード大学のミラー）。距離は赤方偏移ではなく、セファイドなどの測定を含む |
| 結果 | 862 個（距離 0.02〜26 Mpc）。明るさの無い 6 個と、天の川銀河そのものを外した |
| 使う列 | 位置、距離、見かけの長軸 a26、軸の比 b/a、傾き i、ハッブル分類 T、B バンドの絶対等級 |
| 長軸の向き | OpenNGC（CC BY-SA 4.0）。分かるのは 187 個。無ければ種から決める（大マゼラン雲・小マゼラン雲も無い） |
| 日本語の名前 | よく知られた 12 個（アンドロメダ銀河・大マゼラン雲など） |
| 形式 | `public/data/galaxies.json`（約 60 KB） |

## 形と明るさ

**位置・距離・大きさ・傾き・種類・明るさは観測の値。星の並びは種類に合わせて種から作る**（カードにも書く）。

- 太陽から見た長軸の向きと傾きが観測と合うように、円盤の向きを決める（`galaxyFrame`。傾きの表と裏は観測から分からないので種から）
- 楕円・レンズ状（T ≤ 0）は中心が濃い楕円体、渦巻（T = 1〜8）は指数関数の円盤＋ふくらみ＋ 2 本の対数らせん、不規則（T ≥ 9）は塊の集まり
- 光の点の数は `60 × a26^1.2`（30〜60,000 個）。合計は約 40 万個（スマホは 0.3 倍）。見かけが大きい銀河ほど多い
- 明るさは絶対等級と距離からの見かけの等級で決める。**星の見え方（要件 F34）の限界より暗い銀河は消える**。双眼鏡（9 等）ではアンドロメダ銀河・マゼラン雲など明るい銀河が見える

## 行き方

いちばん近い大きな銀河まで、最高速度（秒速 1,000 光年。要件 F17）で大マゼラン雲は約 2.7 分、アンドロメダ銀河は約 42 分かかる。そこまで飛べばワープホールも置ける。

## 確かめたこと（2026-11-05）

- テスト：アンドロメダ銀河の距離と半径、太陽から見た長軸の向き（35 度）と傾き、同じ銀河から同じ点、点の合計の上限
- 画面（WebGPU）：地球からアンドロメダ銀河・大マゼラン雲、アンドロメダ銀河の 6 万 pc 先（渦巻きが見える）

## いまの制限

- 銀河の中に入っても、星は光の点だけ（恒星系にならない）。ワープホールを置くと、住所はいちばん近い天の川銀河の星（`MW-…`）になる。銀河ごとの住所はオーナーの決定が要る
- 26 Mpc より遠い銀河は無い
