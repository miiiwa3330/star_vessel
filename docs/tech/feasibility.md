# 処理的に可能な範囲（Web とネイティブアプリ）

2026-11-04 時点の調べ。提供形態を決めるための材料。要件は [`../product/requirements.md`](../product/requirements.md)。

## 結論

- **今の要件は、Web で処理として十分に可能。** 一人称の移動、実在の天体の位置と動き、写実に寄せすぎない見た目、他のプレイヤーの宇宙船、のどれも Web で無理なく描ける
- **Web とアプリの差が効くのは、今の要件に無いもの。** 惑星に降りて地表を飛ぶ・銀河を写真のように描く・VR など
- **どちらを選んでも同じ課題がある。** 銀河の規模の座標・データの量・同時接続の多さは、提供形態ではなく作り方で解決する（下の「どちらでも同じ課題」）

## 要件ごとの重さ

| やりたいこと | 処理の重さ | Web で | 補足 |
|--------------|-----------|--------|------|
| 惑星・主な衛星の現在位置（公転） | 時刻から軌道の式で計算する。数百個を毎フレーム計算しても軽い | 可能 | 精度の高い式（VSOP87 など）にしても軽い |
| 自転（向き・昼夜） | 時刻から自転の式で計算する。軽い | 可能 | 地球の昼夜も現実と一致する |
| 星空（恒星を点で描く） | 数十万〜数百万個の点なら描ける | 可能 | それより多い分は、遠くをまとめて光の帯などで描く |
| 他のプレイヤーの宇宙船 | 見えている数百機は、同じ形をまとめて描けば軽い | 可能 | 重いのは描画ではなく通信（下記） |
| 惑星の見た目 | 球に画像を貼る程度なら軽い。大気・雲は工夫しだい | 可能 | 写実に寄せすぎない方針と合う |
| 惑星の地表に降りる | 地形を細かく作り続けるため重い | 難しい（スマホは特に） | 今の要件には無い |

## Web とネイティブアプリの差

| 観点 | Web | ネイティブアプリ |
|------|-----|------------------|
| 描画の性能 | WebGPU が 2025 年までに主要ブラウザで使えるようになり、今の要件には十分。ブラウザを通す分、上限はアプリより低い | 端末の性能を引き出しやすい |
| メモリ | タブが使える量に上限がある。スマホのブラウザは特に厳しい → データを必要な分だけ読み込む作りにする | 多く使える |
| 遊び始めるまで | URL を開くだけ。データはその都度ダウンロードする | インストールが要る。データを先に持てる |
| 並列の計算 | Web Worker で計算を分けられるが制約がある | 自由 |
| 通信 | WebSocket・WebRTC。宇宙船の位置を1秒に数回送る程度なら十分 | 方式を自由に選べる |
| 広めやすさ・更新 | リンクで共有でき、更新はすぐ届く | ストアの審査・更新の手間がある |

## どちらでも同じ課題

- **座標の精度**：GPU は 32bit の小数で計算する（WebGPU のシェーダーには 64bit の小数が無い。アプリでも GPU は 32bit が基本）。銀河の規模の座標をそのまま渡すと、遠くで位置がガタつく → 位置は CPU 側で 64bit で持ち、描くときに自分の船を原点にした相対位置へ直す
- **データの量**：天の川銀河の恒星は数千億個あり、どの端末でも全部は持てない → 距離でまとめる・近くの分だけ読む
- **同時接続**：全員に全員の位置を送ると、通信量は人数の2乗で増える → サーバーが近くの船だけを送る仕組みがいる。これはサーバーの設計の話で、提供形態とは関係ない

## 実在のデータで再現できる範囲

「実世界に忠実」にしたときの限界は、処理の重さではなく**データがあるかどうか**で決まる。

| 範囲 | データ | 再現できる度合い |
|------|--------|------------------|
| 太陽系 | 惑星・準惑星・主な衛星の軌道と自転は、公開されている式と値がある | 位置・動きとも現実の時刻に合わせられる |
| 近くの恒星 | 明るい星約12万個をまとめたカタログ（HYG）、ESA の Gaia が観測した約18億個の天体 | 位置・明るさ・色を本物にできる |
| 系外惑星 | 確認済みは約6,000個（NASA Exoplanet Archive、2025年時点） | 見つかっている分だけ。大半の星のまわりの惑星は分かっていない |
| 遠くの星 | 距離が精度よく分かるのは太陽から数千光年程度まで。銀河の直径は約10万光年 | 銀河の大部分は、本物の銀河の形（渦巻きの腕・星の濃さ）に沿って自動で生成するしかない |

- データは使う前にライセンスを確かめ、使ったものと条件を docs に残す（[`../../AGENTS.md`](../../AGENTS.md) の「実装の方針」）
