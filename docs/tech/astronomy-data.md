# 天体の計算とデータ（astronomy-engine・HYG）

どちらも 2026-11-04 に採用した（[`stack.md`](stack.md) の「決まったこと」）。以下は 2026-11-04 に、npm のパッケージと配布元のデータを実際に取得して確かめた内容。

## astronomy-engine：太陽系の「いま」を計算する

| 項目 | 内容 |
|------|------|
| 何か | 時刻を渡すと、天体の位置・向きを返す計算ライブラリ。JavaScript 版のほか、C・Python などにも同じ計算がある |
| 版・更新 | 2.1.19（2023-12 公開）。リポジトリの最終更新は 2025-01 |
| ライセンス | MIT（クレジット表記のみで自由に使える） |
| 精度 | NOVAS（米海軍天文台の計算ソフト）との差が角度で1分（満月の直径の約30分の1）以内。JPL Horizons とも照合している |
| 大きさ | 圧縮前で約130KB。他のライブラリに頼らず、使う関数だけを読み込める（ESM・`sideEffects: false`） |

### できること

| やりたいこと | 関数 | 中身 |
|--------------|------|------|
| 惑星の公転（位置・速度） | `HelioVector`・`HelioState`・`BaryState` | 太陽・水星〜海王星・冥王星・月の位置 |
| 地球から見た月 | `GeoMoon`・`Libration` | 月の位置と、月の見える面の揺れ |
| 木星の4大衛星 | `JupiterMoons` | イオ・エウロパ・ガニメデ・カリスト |
| 自転（軸の向き・回った角度） | `RotationAxis` | 太陽・月・惑星・冥王星。IAU（国際天文学連合）の2015年の式。軸の向きと「本初子午線がどこを向いているか」が出るので、地球の昼夜を現実と一致させられる |
| 座標の変換 | `Rotation_EQJ_GAL` など | 赤道・黄道・銀河の座標を相互に変換する。太陽系と恒星を、銀河の中に置くときに使える |
| その他 | `Illumination`・`LagrangePoint` など | 惑星の明るさ・満ち欠け、ラグランジュ点、日食・月食 |

### できないこと（自分で足す）

- 火星・土星・天王星・海王星の衛星、小惑星、彗星 → 公開されている軌道の値から、自分で計算する
- 土星の環の形 → 見た目として自分で描く
- 時刻の扱いでは、地球の自転で決まる時刻（UT1）と UTC を同じとみなしている。見た目には影響しない

## HYG データベース：本物の星空のデータ

| 項目 | 内容 |
|------|------|
| 何か | 3つの星表（Hipparcos・Yale Bright Star・Gliese）をまとめた恒星のデータ |
| 版・配布元 | v4.4。配布元は Codeberg の `astronexus/hyg`（GitHub の旧リポジトリは更新停止） |
| ライセンス | CC BY-SA 4.0（下記） |
| 大きさ | 119,614個（太陽を含む）。CSV で約34MB、配布の圧縮ファイルで約13MB |

### 中身（実物で数えた値）

| 項目 | 値 |
|------|----|
| 名前のある星（シリウス・ベテルギウスなど） | 549個 |
| 肉眼で見える明るさ（6.5等以下） | 8,921個 |
| 距離が分かる星の距離 | 中央値 約630光年、90%が約1,700光年以内、最も遠くて約3,200光年 |
| 距離が分からない星 | 10,224個（距離の欄が仮の値になっている） |

列は37個。使いそうなものは、位置（`x`・`y`・`z`、単位はパーセク）、明るさ（`mag`・`absmag`）、色（`ci`・`spect`）、名前（`proper`・`bayer`・`con`）、動き（`vx`・`vy`・`vz`）。位置は astronomy-engine と同じ J2000 の赤道座標系なので、太陽系とそのまま重ねられる。

### 使うときの注意

- **そのままは重い。** CSV（約34MB）をブラウザで読ませない。使う列だけを数値の並び（1個あたり約20バイト）に変換し、約2〜3MB に縮めて配る
- **届く範囲は約3,200光年まで。** 銀河（直径約10万光年）のごく一部なので、その外は自動で生成する（[`../product/requirements.md`](../product/requirements.md) の F8）
- **距離の分からない星（10,224個）** は、見た目の空には置けるが、近づくことはできない。扱いを決める必要がある
- **もっと多い星が要るとき**：同じ配布元に AT-HYG（Tycho-2 の約250万個に、Gaia DR3 の距離を足したもの）がある。ライセンスは使う前に確かめる

### CC BY-SA 4.0 で求められること

- **クレジット表記**：画面かクレジットのページに、HYG の名前・作者（David Nash / astronexus）・ライセンスを書く
- **継承**：HYG を変換・加工したデータを配るときは、そのデータも CC BY-SA 4.0 にする。一般的な解釈では、データを読み込むアプリのコードまでは及ばない
- 採用するときは、原文（配布元の `LICENSE`）を読み、表記のしかたを docs に残す

## ほかの候補（2026-11-04 に確かめた）

### 天体の計算

| 候補 | 中身 | ライセンス | 合うか |
|------|------|-----------|--------|
| **astronomy-engine** | 上記 | MIT | **推奨**。軽く、精度が十分で、太陽系の主な天体の公転・自転が揃う |
| astronomia（4.2.0） | 天文計算の教科書（Meeus）の式を集めたもの | MIT | 使えるが、組み立てる手間が多い。自転の式は揃っていない |
| JPL Horizons API | NASA JPL のウェブ API。衛星・小惑星・彗星まで、いちばん正確 | 公開 API | ブラウザから毎フレーム呼ぶものではない。**開発中に一度だけ呼んで、衛星などの軌道の値を集める**のに使える |
| SPICE（NASA の計算ツール）の JavaScript 版（timecraftjs 2.0.0） | 探査機の運用にも使う精密な計算 | Apache-2.0 | データが数十〜数百MBと重く、2022年から更新がない。見た目の用途には過剰 |
| Swiss Ephemeris（sweph） | 精密な天体暦 | AGPL か有料 | ライセンスの条件が厳しい。不採用を推奨 |
| satellite.js（7.1.0） | 地球を回る人工衛星（ISS など）の位置を、公開されている軌道の値から計算 | MIT | 太陽系の天体とは別物。**ISS など本物の人工衛星を置きたくなったら**足せる |

### 星・天体のデータ

| 候補 | 中身 | ライセンス | 合うか |
|------|------|-----------|--------|
| **HYG v4.4** | 約12万個の恒星 | CC BY-SA 4.0 | **推奨**。量と中身のちょうどよさ |
| Yale Bright Star（BSC5） | 肉眼で見える明るい星 約9,000個 | 公開データ | 少なすぎる。HYG に含まれている |
| AT-HYG | 約250万個（Tycho-2 ＋ Gaia DR3 の距離） | 使う前に確かめる | HYG で足りなくなったら |
| Gaia DR3（ESA） | 約18億個。必要な範囲を ESA の検索で切り出す | ESA の公開データ（条件は使う前に確かめる） | 量が多い。遠くまで本物の星を増やしたくなったら |
| OpenNGC | 星雲・星団・銀河 約1万3千個（NGC・IC カタログ） | CC BY-SA 4.0 | 星以外の天体（アンドロメダ銀河・オリオン大星雲など）を置くときに使える |
| NASA Exoplanet Archive | 確認済みの系外惑星 約6,000個 | 公開データ（条件は使う前に確かめる） | 本物の系外惑星を置くときに使える |
| Stellarium・Celestia のデータ | 天文ソフトに同梱の星・天体のデータ | ソフト本体は GPL-2.0。データの条件は個別 | 中身の多くは上の星表と同じ出どころ。条件が分かりにくいので、元の星表を直接使う |
