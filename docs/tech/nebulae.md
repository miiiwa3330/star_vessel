# 星雲

コードは `src/world/nebulae.ts`（読み方・形を作る）、`src/render/nebula-view.ts`（描画）、`tools/build-nebulae.mjs`（データ）。

## データ

2026-11-05 まで「距離の入った一覧が無い」として見送っていた。**SIMBAD の距離の測定値の表（`mesDistance`）がハーバード大学のミラーから取れる**と分かったので入れた。

| 項目 | 内容 |
|------|------|
| 対象 | SIMBAD の分類が HII・EmO・GNe・ISM（電離水素領域など）、PN（惑星状星雲）、SNR（超新星残骸）、RNe（反射星雲）、DNe・Cld・SFR（暗黒星雲。星形成領域は多くが光らない分子雲なので。2026-11-05：最初は光る星雲にして、おおかみ座・へびつかい座の分子雲が地球の空に桃色の大きな塊として見えた）で、距離の測定値があるもの。分子雲（MoC、約 1.8 万個）は目に見えないので外した |
| 結果 | 2,293 個（電離水素領域 1,213・惑星状星雲 820・超新星残骸 113・暗黒星雲 132・反射星雲 15） |
| 距離 | 測定値の**中央値**（pc に直す）。例：オリオン大星雲 473 pc、かに星雲 2,000 pc、環状星雲 815 pc |
| 大きさ | SIMBAD の見かけの大きさ × 距離。無ければ**種類ごとの典型的な値**（565 個。観測の値ではない。カードに「典型的な値」と出る）：電離水素領域 5 pc、惑星状星雲 0.25 pc、超新星残骸 15 pc、反射星雲 1 pc、暗黒星雲 3 pc |
| 形式 | `public/data/nebulae.json`（約 150 KB） |

### よく知られた星雲（`FAMOUS`）

- 26 個に日本語の名前を付けた。SIMBAD で星団などに分類されているもの（M8・M16・北アメリカ星雲など）も星雲として入れる。大きさは OpenNGC（CC BY-SA 4.0）から
- 距離の測定値が無いものは、同じ領域の天体の距離を使う：M43・M78・馬頭星雲 → M42（オリオン座の分子雲）、ばら星雲 → NGC 2244（星雲の中の星団）、カリフォルニア星雲 → ペルセウス座 ξ 星（星雲を光らせている星）、タランチュラ星雲 → 大マゼラン雲
- SIMBAD に距離が無いものは論文の値を書いた：はくちょう座ループ 735 pc（Fesen ほか 2018）、ほ座超新星残骸 287 pc（Dodson ほか 2003）。超新星残骸の大きさは Green（2019）の一覧

## 形と明るさ

**位置・距離・大きさ・種類は観測の値。形は観測の画像ではなく、種類ごとの決まりで種から作る**（カードにも書く）。同じ星雲は誰が見ても同じ形になる。

| 種類 | 形 |
|------|-----|
| 電離水素領域 | ノイズで切り出した雲。赤い水素の光に、中心の青緑の光を混ぜる |
| 惑星状星雲 | 薄い殻。赤道の方が濃い。内側は青緑、外側は赤 |
| 超新星残骸 | ノイズの等高線で切った糸のような薄い殻 |
| 反射星雲 | 青い雲 |
| 暗黒星雲 | 黒い点の集まり（後ろの星を隠す） |

- **大きく見えている順に 6 個**だけ、点の集まり（1 個 6,000 点）で形を見せる。半径 ÷ 距離が 0.003 より小さい星雲は作らない
- それ以外は、本物の見かけの大きさの小さな光（画面で最大 16 ピクセル、3〜7 ピクセルで消える）
- 面の明るさは距離で変わらないので、遠くても近くても暗く保つ。2026-11-05：最初は明るすぎて、地球から桃色の大きな塊が空に並んで見えたので、大きく下げた（要件 F32 のもやを出さない方針）
- 星の見え方（要件 F34）で明るさを変える：肉眼 0.25 倍・双眼鏡 0.67 倍・写真 1 倍（星雲はほとんど肉眼で見えないため）
- 明るさは見た目のための値で、観測の値ではない

## 確かめたこと（2026-11-05）

- テスト：オリオン大星雲・かに星雲・環状星雲の距離の範囲、同じ星雲から同じ形、形が半径の中に収まる、大きく見える順、中にいる星雲
- 画面（WebGPU）：オリオン大星雲（29 pc 先）、らせん星雲の中、はくちょう座ループ、地球からの空

## いまの制限

- 本物の形（オリオン大星雲の翼の形など）は描いていない
- 距離の測定値のばらつきが大きい星雲がある（中央値にしただけ）
