# 星座

コードは `src/world/constellations.ts`（計算）、`src/render/constellation-view.ts`（描画）、`tools/build-constellations.mjs`（データ）。

## データ

| 項目 | 内容 |
|------|------|
| 線と日本語の名前 | [d3-celestial](https://github.com/ofrohn/d3-celestial)（Olaf Frohn、BSD 3-Clause）の `constellations.lines.json`・`constellations.json`。commit `7e720a3`（2026-11-05 取得） |
| 結果 | 89 件（88 星座。へび座は頭と尾に分かれる）、線 741 本、線の端の星 757 個 |
| 形式 | `public/data/constellations.json`。星座ごとに略号・日本語の名前・英語の名前と、線（両端の星の HYG の id）。`constellations.LICENSE.txt` を一緒に置く |

- Stellarium のデータは配布場所が変わっていて取れなかったことと、ライセンス（GPL）の扱いが難しいので使わなかった
- 配布データの線の端は赤経・赤緯だけなので、**いちばん近い 9 等より明るい HYG の星に当てる**（方向のずれは最大 0.41 度）。距離の分からない星（HYG で距離が仮の値の星）は 3 次元に置けないので、その線は描かない（1 か所）

## 3 次元の線にする理由

線の両端を本物の星の 3 次元の位置にしたので、**地球のそばからは星座の形に、離れると崩れた形に見える**（要件 F40）。星座の星は実際には何百光年もばらばらに離れていることが、飛んでいくと分かる。

- 線は星の今の位置（`applyStarMotion` のあと）から作るので、星と線がずれない

## 描き方

- GPU のふつうの線（`THREE.LineSegments`）。WebGPU では太さ 1 ピクセル
- 2026-11-05：太さを選べる `LineSegments2` を先に試したが、線が画面を横切る太い帯になり、離れると消えたのでやめた。星の場面の手前の面がとても近い（1e-6 pc）ためとみている（原因までは確かめていない）
- 太陽から 2,000 pc を超えると薄くし、6,000 pc で消す（線が 1 点に固まって見えるだけなので）
- 画面の中の文字は出さない（デザインの決まり）。照準の先（線のいちばん近いところまで 6 度以内）の星座の線を明るくし、**照準の下に名前を出す**（`constellationAt`）。自分の位置から見た線で選ぶので、どこにいても見えているとおりに選ばれる
- 右のボタン「星座」か C キーで出す・消す。端末に覚える（最初は消しておく）

## 確かめたこと（2026-11-05）

- テスト：89 件そろっている、オリオン座にベテルギウスとリゲルが入る、ベテルギウスの方を見るとオリオン座が選ばれる、線の間を見ても選ばれる
- 画面（WebGPU）：地球のそばでオリオン座の形（ベルト・リゲル・ベテルギウス）が明るくなり名前が出る。太陽から約 700 光年離れると形が崩れる

## いまの制限

- 線は 1 ピクセルで細い
- 星座の境界線（IAU の区画）は描いていない
