# 探査機

コードは `src/world/spacecraft.ts`（位置）、`tools/build-spacecraft.mjs`（データ）。描画は人工衛星の模型と同じ（`src/render/solar-system-view.ts`）。

## データ

`npm run spacecraft`。JPL Horizons の太陽中心・ICRF の位置と速さを、一定の間隔で表にする（`public/data/spacecraft.json`、約 220 KB）。

| 探査機 | 間隔 | 表の期間（2026-11-05 取得） |
|--------|------|------------------------------|
| ボイジャー 1・2 号、パイオニア 10・11 号、ニュー・ホライズンズ | 30 日 | 〜2030-12 |
| ウェッブ、ユークリッド、ガイア、ルーシー、エウロパ・クリッパー、ジュース | 5 日 | 〜2030-12 |
| ソーラー・オービター | 5 日 | 〜2030-11 |
| オシリス・アペックス | 5 日 | 〜2030-03 |
| サイキ | 5 日 | 〜2029-02 |
| パーカー・ソーラー・プローブ | 1 日 | 〜2030-01 |
| ベピコロンボ | 5 日 | 〜2027-04 |
| はやぶさ 2 | 5 日 | 〜2027-01 |
| ヘラ | 5 日 | 〜2027-01 |

- 表の間は**エルミート補間**（位置と速さの両方を使う）でつなぐ。表の期間の外は、端の速さのまま進める。Horizons の予報が伸びたら `npm run spacecraft` で作り直す
- id は `V`＋JPL の番号の絶対値（ボイジャー 1 号＝`V31`）。住所は惑星・衛星とも 0（太陽のまわり）
- 惑星や衛星のまわりを回っている探査機（ジュノー、火星の周回機など）は、周期が短くて表の間隔では追えないので入れていない

## 見た目

- 人工衛星と同じ、箱と太陽電池の板の簡単な模型。大きさはおおよその値（`sizeM`）
- とても遠くても、探しに行けるように光の点を残し、レーダーにも出す
- そばに止まっていられるよう、20 km 以内では基準の天体にする

## 確かめたこと（2026-11-05）

- テスト：表の間の時刻で、Horizons の位置とボイジャー 1 号は 3,000 km 以内、ウェッブは 30,000 km 以内で合う
- 画面（WebGPU）：ボイジャー 1 号とウェッブのそばへ行き、基準の天体になる
