# star_vessel

地球から飛び立ち、世界中のプレイヤーと同じ宇宙を、自分の宇宙船の一人称視点で旅する Web アプリ。

- 惑星の位置・公転・自転は、現実のいまの時刻に合わせて動く
- 星空は本物の恒星のデータ（HYG、約 12 万個）

- ワープホールを置いて、全員で共有できる。名前は宇宙の住所（例：`MW-ORI-SOL-3-1-002`）
- 同じ恒星系にいる他のプレイヤーが、宇宙船（遠くからは航行灯の光）として見える
- 本物の星のデータの外は、本物の銀河の形に沿って星を自動で作る。銀河の外に出ると渦巻きが見える
- 惑星には模様があり、土星には環がある。木星のガリレオ衛星もいまの位置で回る
- 惑星には大気の光の輪があり、土星の環には本体の影が落ちる。恒星に近づくと、表面の粒の模様と光の広がりが見える
- 太陽系の衛星（188 個）と、番号の付いた小惑星（約 90 万個）が、いまの位置で回る
- 自分の宇宙船（3 種類の UFO）を選べて、他のプレイヤーにもその形で見える。一人称と三人称（船のまわりを回り込める）を切り替えられる
- 近くのプレイヤーにスタンプ（絵文字・あいさつ）を送れる。相手の船の上に吹き出しが出る
- 地球のまわりに本物の人工衛星（ISS など約 1,700 機）が、いまの位置で回る
- 実在の星団（プレアデス・オメガ星団など約 6,900 個）、白色矮星・パルサー・ブラックホールがある
- 太陽系の外の恒星にも惑星がある。実在の系外惑星（約 5,000 個。TRAPPIST-1 など）は本物の軌道で、それ以外の恒星には観測の割合に合わせて自動で作る（自動で作る惑星には衛星や環もある）

いまは「世界の創造」の土台の段階（操縦は仮）。サーバーは Cloudflare Workers（手元でだけ動かしている）。

## 動かし方

Node.js 24 以上。

```bash
npm install
cp .dev.vars.example .dev.vars   # BETTER_AUTH_SECRET に openssl rand -base64 32 の値を入れる
npm run db:migrate               # 手元のデータベースにテーブルを作る
npm run dev                      # http://localhost:5173
```

| 操作 | PC | スマホ |
|------|----|--------|
| 向きを変える | ドラッグ | 1 本指でドラッグ |
| 進む | W・S（前後）、A・D（左右）、R・F（上下） | 2 本指で触れている間、前へ |
| 傾き | Q・E | — |
| 視点 | V（三人称では右ドラッグで回り込み、Alt＋ホイールで距離） | 「視点」ボタン（三人称で「ドラッグ：カメラを回す」にすると 1 本指で回り込み） |
| 宇宙船を変える | 右の「宇宙船」 | 同じ |
| スタンプ | 左上の「スタンプ」 | 同じ |
| 速さ | ホイール、＋・−（Shift で 10 倍ずつ。最高は秒速 1,000 光年） | 左の「速く」「遅く」 |
| ワープホール | 右下の「ここにワープホールを置く」（1 人 3 個まで）、「ワープ」の一覧から選んで飛ぶ | 右上 |

## そのほかのコマンド

```bash
npm test         # テスト
npm run check    # 型チェック
npm run build    # ビルド（dist/）
npm run stars    # 星のデータ（public/data/stars.bin）の作り直し
npm run exoplanets # 系外惑星のデータ（public/data/exoplanets.json）の作り直し
npm run moons      # 衛星のデータ（public/data/moons.json）の作り直し
npm run asteroids  # 小惑星のデータ（public/data/asteroids-*.bin）の作り直し
npm run satellites # 人工衛星の軌道要素の写し（public/data/satellites.json）の作り直し
npm run clusters   # 星団のデータ（public/data/clusters.json）の作り直し
npm run compact    # 白色矮星・パルサー・ブラックホールのデータ（public/data/compact.json）の作り直し
```
